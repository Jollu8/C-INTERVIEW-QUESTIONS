Linux-specific команды требуют соответствующей среды; версии стандартов, flags и возможностей инструментов уточняются в ответах и linked documentation.

Overview

Этот документ описывает ключевые области знаний для C++ разработчика в Linux-среде с акцентом на:

Можно использовать как:

  • чеклист навыков
