## Обучение и подготовка к собеседованиям

Структурированная база вопросов, ответов и практики по C++, Linux, сетям и системной разработке. Подготовка к собеседованиям — один из сценариев использования.

**[Маршруты обучения: что читать и что делать](./learning/roadmap.md)**

Маршруты охватывают системную разработку, переход из LTE/NR и подготовку к GPU. Для каждого этапа указаны чтение, практика и критерий освоения. На сайте roadmap доступен по ссылке «Маршруты обучения».

В [Python](./content/10_python/README.md) добавлено 395 вопросов и задач. В [архитектуре компьютеров](./content/12_computer_architecture/README.md) — 384 вопроса и задания с ответами, примерами, типичными ошибками и источниками в 16 темах, с тремя уровнями сложности. [Математика](./content/11_math/README.md) и [GPU](./content/13_gpu/README.md) пока представлены планами.

Репозиторий охватывает не только C/C++, но и широкий инженерный стек:
алгоритмы, concurrency, Linux, networking, инструменты разработки, тестирование, архитектуру, базы данных и Python.

**[Открыть веб-тренажёр](https://jollu8.github.io/C-INTERVIEW-QUESTIONS/)**

У проекта есть веб-интерфейс для подготовки на компьютере и телефоне:

- выбор разделов, подтем и готовых тематических маршрутов;
- тренировки по всем вопросам отмеченных тем без ограничения количества;
- мобильная панель с итогом выбранных вопросов и запуском, доступная при прокрутке;
- roadmap с чтением, упражнениями и критериями освоения;
- вопросы по порядку или случайно, без повторов в подборке;
- раскрытие готовых ответов и фильтр «Только с ответами»;
- переходы к предыдущему и следующему вопросу;
- отметки «Знаю / Повторить» и подборки сложных вопросов;
- поиск по разделам и подтемам;
- экспорт и импорт прогресса в JSON для переноса между устройствами;
- автоматическое сохранение прогресса и продолжение в том же браузере.

Ответы добавлены к части вопросов C/C++, алгоритмов, многопоточности, Linux, сетей и инструментов сборки.
Вопросы без ответов также доступны для самостоятельной подготовки.
Веб-версия публикуется через GitHub Pages; настройка публикации описана ниже.

## 🚀 Quick Start

### Веб-тренажёр

Открой [веб-тренажёр](https://jollu8.github.io/C-INTERVIEW-QUESTIONS/): выбери разделы и подтемы,
порядок вопросов и при необходимости фильтр «Только с ответами». Внизу показано
общее количество вопросов в отмеченных темах. Нажми «Начать», чтобы пройти всю подборку.
Ссылки на темы из плана обучения открывают библиотеку с отмеченной темой: перед запуском можно изменить выбор.
Прогресс сохраняется в этом браузере на этом устройстве.

Для локального запуска открой `web/index.html` из скачанного репозитория
в браузере. Установка сервера не требуется.

При открытии загружается компактный каталог тем. Вопросы и ответы загружаются
отдельно для открываемой темы из `web/topics/`; формулы и подсветка кода подключаются
при открытии вопроса и требуют доступа к CDN.

После изменения материалов пересобери данные сайта:

```bash
python scripts/build_web.py
```

### Публикация на GitHub Pages

В настройках репозитория выбери **Settings → Pages → Build and deployment →
Source: GitHub Actions**. После отправки изменений в `main` workflow
`Deploy practice site` пересоберёт вопросы и опубликует тренажёр.
Его также можно запустить вручную во вкладке Actions.

Адрес после публикации: https://jollu8.github.io/C-INTERVIEW-QUESTIONS/.
Сайт работает на компьютерах и телефонах; прогресс хранится в браузере.
Прогресс локальной HTML-версии не переносится автоматически на GitHub Pages.

Локальная сборка публикуемой версии: `python -m scripts.build_pages`.
Результат находится в `_site/` и не добавляется в Git.

### Проверки и генерация

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Сгенерировать индекс
python scripts/build_index.py

# 3. Посчитать статистику
python scripts/stats.py

# 4. Проверить ссылки
python scripts/validate_links.py

# 5. Проверить метаданные
python scripts/validate_meta.py

# 6. Запустить тесты
pytest
```

## ⚙️ Как работает репозиторий

Проект содержит не только контент, но и пайплайн обработки:

### 1. Индексация

```bash
python scripts/build_index.py
```

- сканирует `content/**/*.md`
- извлекает:
  - заголовки
  - ссылки
  - количество вопросов и наличие ответов единым парсером с веб-тренажёром

- формирует `generated/index.json`

---

### 2. Статистика

```bash
python scripts/stats.py
```

Генерирует:

- общее количество тем
- количество вопросов
- распределение по секциям

→ `generated/stats.json`

`total_questions` и `total_answers` считаются тем же парсером, что использует сайт. Наличие ответа не означает завершённую техническую проверку. `total_topics` учитывает все индексируемые Markdown-файлы, включая планы и оглавления.

---

### 3. Валидация ссылок

```bash
python scripts/validate_links.py
```

Проверяет:

- локальные Markdown-ссылки в `content/**/*.md` вне блоков кода
- существование целевых файлов и якорей

Корневой `README.md` не входит в область проверки.

---

### 4. Валидация метаданных

```bash
python scripts/validate_meta.py
```

Проверяет:

- структуру `index.json`
- обязательные поля
- уникальность `id`
- существование файлов

---

### 5. Тесты

```bash
pytest
```

Покрывают:

- структуру проекта
- ссылки
- уникальность id
- консистентность данных

## 📂 Структура репозитория

```text
content/        — вопросы и темы
generated/      — сгенерированные артефакты
schemas/        — JSON schema
scripts/        — утилиты
templates/      — шаблоны
learning/       — маршруты обучения и конфигурация подборок
web/            — статический тренажёр и HTML-страницы маршрутов
tests/          — проверки
```

---

## ➕ Как добавить новый вопрос

1. Используй шаблон:

```
templates/question_file.md
```

2. Размести файл в нужной секции:

```
content/<section>/<topic>.md
```

3. После добавления:

```bash
python scripts/build_index.py
python scripts/stats.py
python scripts/validate_meta.py
pytest
```
