# 01_Основы

## Лёгкий уровень

1. Что такое язык программирования C++?

   **Ответ:** C++ — компилируемый язык общего назначения с поддержкой процедурного, объектно-ориентированного и обобщённого программирования.

   **Пример:**

   ```cpp
   int main() {
       return 0;
   }
   ```

   **Типичная ошибка:** Считать C++ только расширенной версией C. У языков общая основа, но стандарты и модель типов различаются.

   **Источник:** [Cppreference: C++ language](https://en.cppreference.com/w/cpp/language)

2. Для чего используют C++?

   **Ответ:** C++ используют там, где важны производительность, контроль ресурсов и предсказуемое время работы: в системном ПО, играх, встраиваемых системах, инфраструктуре и высокопроизводительных сервисах.

   **Пример:** Один и тот же язык применяется для драйвера, игрового движка и сетевого сервиса, но требования к архитектуре и безопасности у них различаются.

   **Типичная ошибка:** Выбирать C++ только ради скорости, не учитывая стоимость разработки и сложность безопасного управления ресурсами.

   **Источник:** [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines)

3. Из каких основных этапов состоит создание программы на C++?

   **Ответ:** Обычно процесс включает препроцессирование, компиляцию каждого исходного файла, сборку объектных файлов и линковку. На практике между ними также выполняются генерация зависимостей и проверки.

   **Пример:**

   ```text
   main.cpp -> preprocess -> compile -> main.o -> link -> program
   ```

   **Типичная ошибка:** Называть любую ошибку сборки ошибкой компиляции. Ошибка поиска символа часто возникает уже на этапе линковки.

   **Источник:** [Cppreference: translation phases](https://en.cppreference.com/w/cpp/language/translation_phases)

4. Что делает функция `main()`?

   **Ответ:** В hosted-программе `main` является точкой входа, которую вызывает среда выполнения. Она возвращает код завершения программе-оболочке.

   **Пример:**

   ```cpp
   int main() {
       return 0;
   }
   ```

   **Типичная ошибка:** Считать, что `main` можно вызвать из обычного кода как стандартную функцию программы.

   **Источник:** [Cppreference: main function](https://en.cppreference.com/w/cpp/language/main_function)

5. Почему выполнение программы обычно начинается с `main()`?

   **Ответ:** В обычной hosted-программе стандарт определяет `main` как пользовательскую точку входа после запуска среды выполнения. До неё система и runtime могут выполнить собственную инициализацию.

   **Пример:** Глобальные объекты могут быть инициализированы до входа в `main`, поэтому фактический запуск процесса не сводится к первой строке этой функции.

   **Типичная ошибка:** Ожидать, что `main` всегда является первым исполняемым кодом процесса.

   **Источник:** [Cppreference: main function](https://en.cppreference.com/w/cpp/language/main_function)

6. Что означает `return 0;` в конце `main()`?

   **Ответ:** Нулевой код сообщает вызывающей среде об успешном завершении программы. В `main` достижение закрывающей скобки эквивалентно `return 0;`.

   **Пример:**

   ```cpp
   int main() {
       return 0;
   }
   ```

   **Типичная ошибка:** Путать код возврата процесса с результатом последнего выражения внутри программы.

   **Источник:** [Cppreference: return statement](https://en.cppreference.com/w/cpp/language/return)

7. Для чего подключают заголовочные файлы через `#include`?

   **Ответ:** Директива `#include` передаёт препроцессору содержимое указанного заголовка, чтобы исходный файл видел необходимые объявления и определения, доступные на этом этапе.

   **Пример:**

   ```cpp
   #include <iostream>

   int main() {
       std::cout << "Hello\n";
   }
   ```

   **Типичная ошибка:** Считать `#include` импортом модуля во время выполнения. Это операция препроцессирования до компиляции.

   **Источник:** [Cppreference: include directive](https://en.cppreference.com/w/cpp/preprocessor/include)

8. Что делает директива `#include <iostream>`?

   **Ответ:** Она подключает стандартный заголовок с объявлениями потоков ввода и вывода, включая `std::cin`, `std::cout` и `std::cerr`.

   **Пример:**

   ```cpp
   #include <iostream>

   int main() {
       std::cout << "Hello\n";
   }
   ```

   **Типичная ошибка:** Убирать заголовок, потому что программа иногда случайно компилируется благодаря косвенным включениям из других заголовков.

   **Источник:** [Cppreference: standard library header](https://en.cppreference.com/w/cpp/header/iostream)

9. Для чего нужен `std::cout`?

   **Ответ:** `std::cout` — стандартный поток вывода, связанный с обычным выводом программы. В него записывают данные оператором `<<`.

   **Пример:**

   ```cpp
   #include <iostream>

   int main() {
       std::cout << "value = " << 42 << '\n';
   }
   ```

   **Типичная ошибка:** Использовать `std::endl` для каждой строки без необходимости: он дополнительно сбрасывает буфер.

   **Источник:** [Cppreference: std::cout](https://en.cppreference.com/w/cpp/io/cout)

10. Для чего нужен `std::cin`?

    **Ответ:** `std::cin` — стандартный поток форматированного ввода. Оператор `>>` извлекает данные и преобразует их согласно типу переменной.

    **Пример:**

    ```cpp
    #include <iostream>

    int main() {
        int value{};
        if (std::cin >> value) {
            std::cout << value << '\n';
        }
    }
    ```

    **Типичная ошибка:** Не проверять состояние потока после ввода: при неверном формате переменная может не получить ожидаемое значение.

    **Источник:** [Cppreference: std::cin](https://en.cppreference.com/w/cpp/io/cin)
11. Чем отличается вывод от ввода?

    **Ответ:** Ввод получает данные из источника, например `std::cin`, а вывод отправляет данные в поток, например `std::cout`.

    **Пример:**

    ```cpp
    int value{};
    std::cin >> value;
    std::cout << value << '\n';
    ```

    **Типичная ошибка:** Считать, что `std::cin` и `std::cout` работают только с консолью. Потоки абстрагируют источник или назначение данных.

    **Источник:** [Cppreference: iostream library](https://en.cppreference.com/w/cpp/io)

12. Что такое оператор в C++?

    **Ответ:** Оператор — это конструкция языка, задающая операцию над одним или несколькими операндами, например сложение, сравнение или присваивание.

    **Пример:**

    ```cpp
    int total = left + right;
    bool positive = total > 0;
    ```

    **Типичная ошибка:** Путать оператор `=` присваивания с оператором `==` сравнения.

    **Источник:** [Cppreference: operators](https://en.cppreference.com/w/cpp/language/operators)

13. Что такое инструкция в C++?

    **Ответ:** Инструкция, или statement, задаёт действие, которое может быть выполнено. К инструкциям относятся выражения с `;`, составные инструкции, условия и циклы.

    **Пример:**

    ```cpp
    int value = 42;  // expression statement
    if (value > 0) { // selection statement
       value--;
    }
    ```

    **Типичная ошибка:** Считать каждую строку исходного файла отдельной инструкцией: одна инструкция может занимать несколько строк.

    **Источник:** [Cppreference: statements](https://en.cppreference.com/w/cpp/language/statements)

14. Зачем в конце большинства инструкций ставится `;`?

    **Ответ:** Точка с запятой завершает expression statement и некоторые объявления, позволяя компилятору определить границу конструкции.

    **Пример:**

    ```cpp
    int value = 42;
    value += 1;
    ```

    **Типичная ошибка:** Добавлять `;` после заголовка `if`, из-за чего тело условия становится пустой инструкцией.

    **Источник:** [Cppreference: expression statement](https://en.cppreference.com/w/cpp/language/statements)

15. Что такое комментарий в коде?

    **Ответ:** Комментарий — текст для читателя, который игнорируется компилятором после обработки комментариев на ранней стадии трансляции.

    **Пример:**

    ```cpp
    // Однострочный комментарий
    int value = 42; /* Короткое пояснение */
    ```

    **Типичная ошибка:** Оставлять устаревший комментарий вместо обновления кода или объяснять очевидное, не раскрывая причину решения.

    **Источник:** [Cppreference: comments](https://en.cppreference.com/w/cpp/comments)

16. Чем отличаются `//` и `/* ... */`?

    **Ответ:** `//` начинает комментарий до конца строки, а `/* ... */` ограничивает многострочный комментарий парой разделителей.

    **Пример:**

    ```cpp
    // Комментарий до конца строки
    /* Комментарий
      на нескольких строках */
    ```

    **Типичная ошибка:** Пытаться вкладывать блочные комментарии: стандартный синтаксис `/* ... */` не поддерживает их вложенность.

    **Источник:** [Cppreference: comments](https://en.cppreference.com/w/cpp/comments)

17. Что такое идентификатор?

    **Ответ:** Идентификатор — имя сущности программы, например переменной, функции, типа или пространства имён.

    **Пример:** В объявлении `int item_count{};` идентификатором является `item_count`.

    **Типичная ошибка:** Начинать идентификатор с цифры или использовать пробелы. Для составных имён применяют, например, `item_count`.

    **Источник:** [Cppreference: identifier](https://en.cppreference.com/w/cpp/language/identifiers)

18. Какие правила существуют для имён переменных в C++?

    **Ответ:** Имя может содержать буквы, цифры и символ `_`, но не может начинаться с цифры. Имя не должно совпадать с ключевым словом; регистр символов различается.

    **Пример:** `item_count`, `value2` и `_internal` синтаксически допустимы, но имена, начинающиеся с `_` в глобальной области, могут быть зарезервированы реализацией.

    **Типичная ошибка:** Использовать зарезервированные имена или полагаться на различие вроде `Value` и `value` без необходимости.

    **Источник:** [Cppreference: identifier](https://en.cppreference.com/w/cpp/language/identifiers)

19. Что такое ключевое слово языка?

    **Ответ:** Ключевое слово — зарезервированный токен языка с особым смыслом, например `if`, `class`, `return` или `constexpr`.

    **Пример:**

    ```cpp
    if (ready) {
       return 0;
    }
    ```

    **Типичная ошибка:** Пытаться назвать переменную ключевым словом: `int class = 1;` некорректно.

    **Источник:** [Cppreference: keywords](https://en.cppreference.com/w/cpp/keyword)

20. Можно ли назвать переменную `int` или `while`?

    **Ответ:** Нет. `int` и `while` являются ключевыми словами и зарезервированы синтаксисом языка.

    **Пример:** Используйте описательное имя, например `int count{};`, вместо `int int{};`.

    **Типичная ошибка:** Пытаться обойти ограничение необычным регистром без причины: `Int` технически другое имя, но ухудшает читаемость и стиль кода.

    **Источник:** [Cppreference: keywords](https://en.cppreference.com/w/cpp/keyword)

21. Что такое переменная?

    **Ответ:** Переменная — именованная область памяти с типом и временем жизни, значение которой может изменяться.

    **Пример:** `int count{};` объявляет переменную `count` типа `int` и инициализирует её нулём.

    **Типичная ошибка:** Использовать переменную до инициализации.

    **Источник:** [Cppreference: object](https://en.cppreference.com/w/cpp/language/object)

22. Что значит “объявить переменную”?

    **Ответ:** Объявить переменную — сообщить компилятору её имя и тип, а для определения также создать соответствующий объект.

    **Пример:** `extern int count;` — объявление, а `int count{};` — определение.

    **Типичная ошибка:** Путать объявление с присваиванием нового значения.

    **Источник:** [Cppreference: declarations](https://en.cppreference.com/w/cpp/language/declarations)

23. Что значит “инициализировать переменную”?

    **Ответ:** Инициализация — получение объектом начального значения в момент создания.

    **Пример:** `int value{42};` инициализирует `value` значением `42`.

    **Типичная ошибка:** Считать последующее `value = 42;` инициализацией: это уже присваивание.

    **Источник:** [Cppreference: initialization](https://en.cppreference.com/w/cpp/language/initialization)

24. Чем отличается объявление переменной от присваивания значения?

    **Ответ:** Объявление вводит имя и тип, а присваивание записывает новое значение в уже существующий объект.

    **Пример:** `int value{};` создаёт объект, `value = 42;` изменяет его значение.

    **Типичная ошибка:** Пытаться присвоить значение объекту, который не был создан или недоступен в текущей области.

    **Источник:** [Cppreference: assignment operators](https://en.cppreference.com/w/cpp/language/operator_assignment)

25. Что делает оператор `=`?

    **Ответ:** Оператор присваивания вычисляет правую часть и записывает результат в левый операнд, если тот допускает запись.

    **Пример:** `int value{}; value = 7;`.

    **Типичная ошибка:** Читать `a = b` как математическое равенство: в C++ это действие присваивания.

    **Источник:** [Cppreference: assignment operators](https://en.cppreference.com/w/cpp/language/operator_assignment)

26. Чем отличаются `==` и `=`?

    **Ответ:** `=` присваивает значение, а `==` сравнивает два значения и возвращает `bool`.

    **Пример:** `if (value == 0) {}` проверяет условие, а `value = 0;` изменяет объект.

    **Типичная ошибка:** Написать присваивание внутри условия вместо сравнения.

    **Источник:** [Cppreference: comparison operators](https://en.cppreference.com/w/cpp/language/operator_comparison)

27. Какие арифметические операторы есть в C++?

    **Ответ:** Основные операторы — `+`, `-`, `*`, `/` и `%`; у числовых типов также есть составные формы присваивания.

    **Пример:** `sum += value; remainder = left % right;`.

    **Типичная ошибка:** Делить целые числа и ожидать дробный результат.

    **Источник:** [Cppreference: arithmetic operators](https://en.cppreference.com/w/cpp/language/operator_arithmetic)

28. Что делает оператор `%`?

    **Ответ:** Для целых типов `%` возвращает остаток от целочисленного деления.

    **Пример:** `17 % 5` равно `2`.

    **Типичная ошибка:** Использовать `%` с нулевым делителем: это неопределённое поведение для целочисленных операндов.

    **Источник:** [Cppreference: arithmetic operators](https://en.cppreference.com/w/cpp/language/operator_arithmetic)

29. Что такое целочисленное деление?

    **Ответ:** Деление двух целых операндов даёт целочисленный результат с усечением дробной части к нулю.

    **Пример:** `7 / 2` равно `3`, а `-7 / 2` равно `-3`.

    **Типичная ошибка:** Забыть привести хотя бы один операнд к `double`, когда нужен дробный результат.

    **Источник:** [Cppreference: arithmetic operators](https://en.cppreference.com/w/cpp/language/operator_arithmetic)

30. Что вернёт выражение `7 / 2` для целых чисел?

    **Ответ:** Результатом будет целое число `3`, потому что оба операнда имеют целочисленный тип.

    **Пример:** `double ratio = 7.0 / 2;` уже даёт `3.5`.

    **Типичная ошибка:** Ожидать `3.5` от выражения `7 / 2` до присваивания в `double`.

    **Источник:** [Cppreference: arithmetic operators](https://en.cppreference.com/w/cpp/language/operator_arithmetic)

31. Что такое логический тип значения?

    **Ответ:** Логическое значение описывает истинность утверждения и представляется типом `bool`.

    **Пример:** `bool ready = size > 0;`.

    **Типичная ошибка:** Использовать целые числа вместо `bool` без причины и скрывать смысл условия.

    **Источник:** [Cppreference: fundamental types](https://en.cppreference.com/w/cpp/language/types)

32. Какие значения может принимать `bool`?

    **Ответ:** `bool` принимает `true` или `false`. При преобразовании в число они дают `1` и `0` соответственно.

    **Пример:** `bool enabled{true}; int flag = enabled;`.

    **Типичная ошибка:** Считать любое ненулевое значение отдельным логическим состоянием: после преобразования оно становится `true`.

    **Источник:** [Cppreference: bool type](https://en.cppreference.com/w/cpp/language/types)

33. Что такое логические операторы `&&`, `||`, `!`?

    **Ответ:** `&&` означает логическое И, `||` — ИЛИ, а `!` инвертирует логическое значение. `&&` и `||` используют короткое замыкание.

    **Пример:** `if (pointer != nullptr && pointer->ready()) {}`.

    **Типичная ошибка:** Путать `&&` и `&`, которые имеют разный смысл.

    **Источник:** [Cppreference: logical operators](https://en.cppreference.com/w/cpp/language/operator_logical)

34. Что такое операторы сравнения?

    **Ответ:** Операторы `==`, `!=`, `<`, `>`, `<=` и `>=` сравнивают операнды и обычно возвращают `bool`.

    **Пример:** `bool in_range = value >= low && value <= high;`.

    **Типичная ошибка:** Сравнивать числа с плавающей точкой на точное равенство без учёта погрешности.

    **Источник:** [Cppreference: comparison operators](https://en.cppreference.com/w/cpp/language/operator_comparison)

35. Какие результаты могут давать сравнения?

    **Ответ:** Сравнение даёт `true` или `false`; при использовании в числовом контексте они преобразуются в `1` или `0`.

    **Пример:** `int result = (5 > 3);` получает значение `1`.

    **Типичная ошибка:** Путать логический результат сравнения с разностью двух чисел.

    **Источник:** [Cppreference: boolean conversions](https://en.cppreference.com/w/cpp/language/implicit_conversion)

36. Что делает конструкция `if`?

    **Ответ:** `if` вычисляет условие и выполняет одну ветвь, если оно истинно, а при наличии `else` — другую, если ложно.

    **Пример:** `if (value > 0) { std::cout << "positive"; }`.

    **Типичная ошибка:** Забывать фигурные скобки и случайно связывать с условием только одну инструкцию.

    **Источник:** [Cppreference: if statement](https://en.cppreference.com/w/cpp/language/if)

37. Когда используется `else`?

    **Ответ:** `else` задаёт ветвь, которая выполняется, если условие соответствующего `if` ложно.

    **Пример:** `if (ready) start(); else wait();`.

    **Типичная ошибка:** Не учитывать правило «висячего else»: без скобок `else` относится к ближайшему незавершённому `if`.

    **Источник:** [Cppreference: if statement](https://en.cppreference.com/w/cpp/language/if)

38. Для чего нужен `else if`?

    **Ответ:** `else if` позволяет последовательно проверить несколько взаимоисключающих условий.

    **Пример:** `if (score >= 90) grade = 'A'; else if (score >= 60) grade = 'C';`.

    **Типичная ошибка:** Расставлять условия в неправильном порядке, из-за чего более общее условие перехватывает все случаи.

    **Источник:** [Cppreference: if statement](https://en.cppreference.com/w/cpp/language/if)

39. Что такое вложенный `if`?

    **Ответ:** Вложенный `if` находится внутри другой ветви и проверяет дополнительное условие после выполнения внешнего.

    **Пример:** `if (connected) { if (authenticated) open_session(); }`.

    **Типичная ошибка:** Создавать глубокую вложенность вместо раннего выхода или объединения условий.

    **Источник:** [Cppreference: if statement](https://en.cppreference.com/w/cpp/language/if)

40. Что делает `switch`?

    **Ответ:** `switch` сравнивает целочисленное или перечислимое выражение с метками `case` и передаёт управление совпавшей ветви.

    **Пример:** `switch (command) { case 1: start(); break; default: stop(); }`.

    **Типичная ошибка:** Забыть `break` и получить непреднамеренное прохождение в следующую ветвь.

    **Источник:** [Cppreference: switch statement](https://en.cppreference.com/w/cpp/language/switch)

41. Когда удобнее использовать `switch`, а когда `if`?

    **Ответ:** `switch` удобен для фиксированного набора дискретных значений, а `if` — для диапазонов, сложных выражений и условий разных типов.

    **Пример:** Команды enum подходят для `switch`, а проверка `temperature > limit` — для `if`.

    **Типичная ошибка:** Использовать `switch` для условий, которые он не умеет выразить напрямую.

    **Источник:** [Cppreference: switch statement](https://en.cppreference.com/w/cpp/language/switch)

42. Для чего внутри `switch` нужен `break`?

    **Ответ:** `break` завершает ближайший `switch` и передаёт управление после него.

    **Пример:** `case 1: start(); break;` не выполняет тело `case 2`.

    **Типичная ошибка:** Считать отсутствие `break` всегда ошибкой: намеренный fallthrough должен быть явно документирован.

    **Источник:** [Cppreference: break statement](https://en.cppreference.com/w/cpp/language/break)

43. Что делает ветка `default`?

    **Ответ:** `default` выполняется, если ни одна метка `case` не совпала со значением `switch`.

    **Пример:** `default: report_unknown_command(); break;`.

    **Типичная ошибка:** Использовать `default` для сокрытия невозможных состояний вместо их диагностики.

    **Источник:** [Cppreference: switch statement](https://en.cppreference.com/w/cpp/language/switch)

44. Что такое цикл `while`?

    **Ответ:** `while` повторяет тело, пока его условие истинно; условие проверяется перед каждой итерацией.

    **Пример:** `while (input.has_next()) { input.read(); }`.

    **Типичная ошибка:** Не изменять состояние, от которого зависит условие, и получить бесконечный цикл.

    **Источник:** [Cppreference: while loop](https://en.cppreference.com/w/cpp/language/while)

45. Чем `while` отличается от `do while`?

    **Ответ:** `while` может не выполнить тело ни разу, а `do while` сначала выполняет тело и только потом проверяет условие.

    **Пример:** Меню, которое должно показаться хотя бы один раз, подходит для `do while`.

    **Типичная ошибка:** Проверять входные данные после использования, когда нужна предварительная проверка через `while`.

    **Источник:** [Cppreference: do-while loop](https://en.cppreference.com/w/cpp/language/do)

46. В каком случае `do while` выполнится хотя бы один раз?

    **Ответ:** Всегда: условие `do while` вычисляется после первой итерации тела.

    **Пример:** `do { read_command(); } while (command != quit);`.

    **Типичная ошибка:** Размещать в теле операцию, которая небезопасна до проверки входных данных.

    **Источник:** [Cppreference: do-while loop](https://en.cppreference.com/w/cpp/language/do)

47. Что такое цикл `for`?

    **Ответ:** `for` объединяет инициализацию, условие продолжения и итерацию в одной конструкции.

    **Пример:** `for (int i = 0; i < 3; ++i) { process(i); }`.

    **Типичная ошибка:** Изменять счётчик и в теле, и в третьей части цикла без ясной необходимости.

    **Источник:** [Cppreference: for loop](https://en.cppreference.com/w/cpp/language/for)

48. Из каких частей состоит заголовок цикла `for`?

    **Ответ:** В обычном `for` есть инициализация, условие и выражение итерации, разделённые `;`. Каждая часть может быть опущена.

    **Пример:** `for (std::size_t i{}; i < values.size(); ++i) {}`.

    **Типичная ошибка:** Забыть условие или шаг и случайно создать бесконечный цикл.

    **Источник:** [Cppreference: for loop](https://en.cppreference.com/w/cpp/language/for)

49. Что делает `break` в цикле?

    **Ответ:** `break` немедленно завершает ближайший цикл и передаёт управление после него.

    **Пример:** `for (;;) { if (done) break; work(); }`.

    **Типичная ошибка:** Ожидать, что `break` завершит все вложенные циклы.

    **Источник:** [Cppreference: break statement](https://en.cppreference.com/w/cpp/language/break)

50. Что делает `continue` в цикле?

    **Ответ:** `continue` пропускает оставшуюся часть текущей итерации и переходит к следующей проверке или шагу цикла.

    **Пример:** `for (int value : values) { if (value < 0) continue; process(value); }`.

    **Типичная ошибка:** В цикле `while` пропустить изменение состояния и получить бесконечное повторение.

    **Источник:** [Cppreference: continue statement](https://en.cppreference.com/w/cpp/language/continue)

51. Что такое бесконечный цикл?

    **Ответ:** Бесконечный цикл не достигает условия завершения и продолжает выполняться, пока его не остановит `break`, ошибка или внешняя среда.

    **Пример:** `for (;;) { serve_request(); }` может быть намеренным циклом сервера.

    **Типичная ошибка:** Создать бесконечный цикл из-за переполнения счётчика или неизменяемого условия.

    **Источник:** [Cppreference: for loop](https://en.cppreference.com/w/cpp/language/for)

52. Как можно случайно создать бесконечный цикл?

    **Ответ:** Например, не изменить счётчик, ошибиться в направлении шага или использовать условие, которое никогда не становится ложным.

    **Пример:** `for (int i = 0; i < 10; --i) {}` никогда не достигнет `i >= 10`.

    **Типичная ошибка:** Проверять только нормальный путь и не тестировать граничные значения.

    **Источник:** [Cppreference: for loop](https://en.cppreference.com/w/cpp/language/for)

53. Что такое вложенные циклы?

    **Ответ:** Вложенные циклы — цикл внутри тела другого цикла; внутренний выполняется для каждой итерации внешнего.

    **Пример:** Два цикла по строкам и столбцам матрицы.

    **Типичная ошибка:** Не учитывать произведение размеров и получить неожиданную сложность `O(n * m)` или хуже.

    **Источник:** [Cppreference: statements](https://en.cppreference.com/w/cpp/language/statements)

54. Что такое блок кода?

    **Ответ:** Блок — последовательность инструкций в фигурных скобках `{}`; он образует область видимости локальных имён.

    **Пример:** `if (ready) { int status = 1; use(status); }`.

    **Типичная ошибка:** Обращаться к переменной после закрытия блока, где она была объявлена.

    **Источник:** [Cppreference: compound statement](https://en.cppreference.com/w/cpp/language/statement)

55. Что такое область видимости переменной?

    **Ответ:** Область видимости — часть исходного кода, где имя можно использовать без квалификации.

    **Пример:** Переменная внутри блока скрывает одноимённую внешнюю переменную в этом блоке.

    **Типичная ошибка:** Путать область видимости имени со временем жизни объекта.

    **Источник:** [Cppreference: scope](https://en.cppreference.com/w/cpp/language/scope)

56. Где “живёт” локальная переменная?

    **Ответ:** Локальная переменная обычно имеет автоматическое время хранения: создаётся при достижении объявления и уничтожается при выходе из блока.

    **Пример:** `void f() { std::string text; }` уничтожает `text` при выходе из `f`.

    **Типичная ошибка:** Возвращать указатель или ссылку на локальный объект после его уничтожения.

    **Источник:** [Cppreference: storage duration](https://en.cppreference.com/w/cpp/language/storage_duration)

57. Чем локальная переменная отличается от глобальной?

    **Ответ:** Локальная объявлена внутри функции или блока и ограничена их областью, а глобальная находится на уровне файла/пространства имён и доступна шире.

    **Пример:** Локальное `int count{}` безопаснее изолирует состояние функции, чем глобальное `count`.

    **Типичная ошибка:** Делать данные глобальными только для удобства передачи между функциями.

    **Источник:** [Cppreference: storage duration](https://en.cppreference.com/w/cpp/language/storage_duration)

58. Что такое глобальная переменная?

    **Ответ:** Это переменная, объявленная вне функций и классов на уровне пространства имён; обычно она имеет статическое время хранения.

    **Пример:** `int total_requests{};` вне функций — глобальный объект в глобальном пространстве имён.

    **Типичная ошибка:** Не учитывать порядок инициализации глобальных объектов из разных единиц трансляции.

    **Источник:** [Cppreference: storage duration](https://en.cppreference.com/w/cpp/language/storage_duration)

59. Почему чрезмерное использование глобальных переменных считается плохой практикой?

    **Ответ:** Глобальное изменяемое состояние создаёт скрытые зависимости, усложняет тестирование и повышает риск конфликтов между частями программы.

    **Пример:** Передача состояния через параметр функции делает зависимость явной.

    **Типичная ошибка:** Заменять глобальной переменной нормальный интерфейс класса или функции.

    **Источник:** [C++ Core Guidelines: globals](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#is-globals)

60. Что такое константа?

    **Ответ:** В разговорной практике константой называют значение, которое не должно изменяться после инициализации; в C++ это часто объект с `const` или константное выражение.

    **Пример:** `const int limit{100};` нельзя изменить после создания.

    **Типичная ошибка:** Путать `const`-объект с `constexpr`: `constexpr` дополнительно требует пригодности значения для вычисления на этапе компиляции.

    **Источник:** [Cppreference: cv qualifiers](https://en.cppreference.com/w/cpp/language/cv)
61. Для чего используют `const`?

    **Ответ:** `const` запрещает изменять объект через данное имя и делает намерение неизменяемости частью интерфейса.

    **Пример:** `const int limit{100};` нельзя переназначить.

    **Типичная ошибка:** Думать, что `const int*` и `int* const` означают одно и то же.

    **Источник:** [Cppreference: cv qualifiers](https://en.cppreference.com/w/cpp/language/cv)

62. Чем переменная `const` отличается от обычной переменной?

    **Ответ:** `const`-переменная должна быть инициализирована и после этого не может быть изменена через своё имя.

    **Пример:** `const std::string name{"Ada"};` нельзя использовать слева от `=`.

    **Типичная ошибка:** Объявить `const` без начального значения для обычного объекта.

    **Источник:** [Cppreference: const qualifier](https://en.cppreference.com/w/cpp/language/cv)

63. Что такое литерал?

    **Ответ:** Литерал — запись значения непосредственно в исходном коде, например `42`, `3.14`, `'x'` или `"text"`.

    **Пример:** `int count = 42;` содержит целочисленный литерал `42`.

    **Типичная ошибка:** Путать тип литерала с типом переменной, в которую его записывают.

    **Источник:** [Cppreference: literals](https://en.cppreference.com/w/cpp/language/expressions)

64. Какие литералы вы знаете в C++?

    **Ответ:** Есть целочисленные, вещественные, символьные, строковые, булевы, указательные `nullptr` и пользовательские литералы.

    **Пример:** `42`, `2.5`, `'a'`, `"abc"`, `true`, `nullptr`.

    **Типичная ошибка:** Считать `"a"` символьным литералом: это строковый литерал, а `'a'` — символьный.

    **Источник:** [Cppreference: literals](https://en.cppreference.com/w/cpp/language/expressions)

65. Чем отличаются символьный и строковый литералы?

    **Ответ:** `'A'` — один символьный литерал, а `"A"` — массив символов с завершающим нулём, который обычно преобразуется в указатель.

    **Пример:** `char letter{'A'}; const char* text{"A"};`.

    **Типичная ошибка:** Передать строковый литерал туда, где ожидается `char`.

    **Источник:** [Cppreference: character literal](https://en.cppreference.com/w/cpp/language/character_literal)

66. Что такое escape-последовательности?

    **Ответ:** Это специальные записи внутри литералов, обозначающие символы или значения, которые неудобно записывать напрямую.

    **Пример:** `"line 1\nline 2"` содержит перевод строки.

    **Типичная ошибка:** Забыть, что обратная косая черта начинает escape-последовательность, и некорректно записать путь или regex.

    **Источник:** [Cppreference: escape sequences](https://en.cppreference.com/w/cpp/language/escape)

67. Для чего нужен `\n`?

    **Ответ:** `\n` обозначает символ новой строки в символьном или строковом литерале.

    **Пример:** `std::cout << "first\nsecond";` выводит две строки.

    **Типичная ошибка:** Считать `\n` переносом курсора независимо от платформы: текстовые потоки могут преобразовывать окончания строк.

    **Источник:** [Cppreference: escape sequences](https://en.cppreference.com/w/cpp/language/escape)

68. Для чего нужен `\t`?

    **Ответ:** `\t` обозначает горизонтальную табуляцию.

    **Пример:** `std::cout << "name\tvalue\n";` разделяет столбцы табуляцией.

    **Типичная ошибка:** Ожидать фиксированное число пробелов: ширина отображения табуляции зависит от среды.

    **Источник:** [Cppreference: escape sequences](https://en.cppreference.com/w/cpp/language/escape)

69. Что такое `std::endl`?

    **Ответ:** `std::endl` записывает перевод строки в поток и выполняет сброс буфера потока.

    **Пример:** `std::cout << "done" << std::endl;`.

    **Типичная ошибка:** Использовать `std::endl` в горячом цикле вместо `\n` и получать лишние сбросы буфера.

    **Источник:** [Cppreference: std::endl](https://en.cppreference.com/w/cpp/io/manip/endl)

70. Чем `'\n'` отличается от `std::endl`?

    **Ответ:** `'\n'` только записывает символ новой строки, а `std::endl` дополнительно вызывает `flush`.

    **Пример:** Для обычного буферизованного вывода чаще достаточно `std::cout << '\n';`.

    **Типичная ошибка:** Использовать `flush` как замену корректной синхронизации или логированию.

    **Источник:** [Cppreference: std::endl](https://en.cppreference.com/w/cpp/io/manip/endl)

71. Для чего нужен `using namespace std;`?

    **Ответ:** Директива делает имена из пространства `std` доступными без префикса `std::` в области действия директивы.

    **Пример:** После неё можно писать `cout`, а без неё — `std::cout`.

    **Типичная ошибка:** Размещать директиву в заголовочном файле и загрязнять пространство имён всех подключающих файлов.

    **Источник:** [Cppreference: using directive](https://en.cppreference.com/w/cpp/language/namespace)

72. Почему `using namespace std;` часто не рекомендуют в больших проектах?

    **Ответ:** Она может вызвать конфликты имён и скрыть происхождение символов, особенно при подключении новых библиотек.

    **Пример:** Явное `std::vector` сразу показывает, какой тип используется.

    **Типичная ошибка:** Считать сокращение записи достаточной причиной для глобальной директивы.

    **Источник:** [C++ Core Guidelines: namespaces](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#sf7-dont-write-using-directives-in-a-header-file)

73. Что такое заголовочный файл?

    **Ответ:** Заголовочный файл обычно содержит объявления, типы, шаблоны и встроенные определения, которые могут использовать несколько исходных файлов.

    **Пример:** `math.hpp` может объявлять `int add(int, int);`.

    **Типичная ошибка:** Помещать обычное определение глобальной функции в заголовок без `inline`, что вызывает множественные определения.

    **Источник:** [Cppreference: translation units](https://en.cppreference.com/w/cpp/language/translation_phases)

74. Чем заголовочный файл отличается от исходного файла `.cpp`?

    **Ответ:** `.cpp` обычно компилируется как отдельная единица трансляции, а заголовок подключается в одну или несколько единиц через `#include`.

    **Пример:** Объявление функции помещают в `math.hpp`, реализацию — в `math.cpp`.

    **Типичная ошибка:** Подключать `.cpp` вместо компиляции его отдельно и получать множественные определения.

    **Источник:** [Cppreference: translation unit](https://en.cppreference.com/w/cpp/language/translation_phases)

75. Что такое функция?

    **Ответ:** Функция — именованный блок кода с параметрами и возвращаемым типом, который можно вызвать из других частей программы.

    **Пример:** `int square(int value) { return value * value; }`.

    **Типичная ошибка:** Делать функцию слишком большой и смешивать в ней несколько независимых обязанностей.

    **Источник:** [Cppreference: functions](https://en.cppreference.com/w/cpp/language/functions)

76. Как объявить простую функцию без параметров?

    **Ответ:** Нужно указать возвращаемый тип, имя и пустой список параметров; `void` означает отсутствие результата.

    **Пример:** `void log_start();` — объявление функции без параметров.

    **Типичная ошибка:** В старом стиле C писать `void log_start();` иначе, чем `void log_start(void);`; в C++ пустые скобки уже означают отсутствие параметров.

    **Источник:** [Cppreference: function declaration](https://en.cppreference.com/w/cpp/language/function)

77. Что такое параметры функции?

    **Ответ:** Параметры — имена и типы, указанные в объявлении функции и принимающие значения при вызове.

    **Пример:** В `int sum(int left, int right)` `left` и `right` — параметры.

    **Типичная ошибка:** Путать параметры объявления с фактическими аргументами вызова.

    **Источник:** [Cppreference: function parameters](https://en.cppreference.com/w/cpp/language/function)

78. Что такое аргументы функции?

    **Ответ:** Аргументы — выражения, переданные в функцию при конкретном вызове.

    **Пример:** В `sum(a, 2)` аргументы — `a` и `2`.

    **Типичная ошибка:** Игнорировать порядок и типы аргументов, от которых зависит выбор перегруженной функции.

    **Источник:** [Cppreference: function call](https://en.cppreference.com/w/cpp/language/operator_other)

79. Чем объявление функции отличается от её определения?

    **Ответ:** Объявление сообщает сигнатуру функции, а определение дополнительно содержит её тело.

    **Пример:** `int sum(int, int);` — объявление, `int sum(int a, int b) { return a + b; }` — определение.

    **Типичная ошибка:** Объявить функцию и забыть предоставить единственное определение при линковке.

    **Источник:** [Cppreference: function declaration](https://en.cppreference.com/w/cpp/language/function)

80. Для чего нужен прототип функции?

    **Ответ:** Прототип позволяет компилятору проверить вызов функции до её определения и выполнить корректное разрешение типов.

    **Пример:** Заголовок с `int sum(int, int);` можно подключить до вызова `sum`.

    **Типичная ошибка:** Дублировать прототипы вручную в разных файлах и рассинхронизировать их.

    **Источник:** [Cppreference: function declaration](https://en.cppreference.com/w/cpp/language/function)

81. Что такое тип возвращаемого значения функции?

    **Ответ:** Это тип результата, который функция возвращает через `return`; он является частью объявления функции.

    **Пример:** `double average(int total, int count)` возвращает `double`.

    **Типичная ошибка:** Возвращать значение из функции `void` или не возвращать результат из функции с другим типом.

    **Источник:** [Cppreference: return statement](https://en.cppreference.com/w/cpp/language/return)

82. Когда используют `void`?

    **Ответ:** `void` используют для функции, которая не возвращает значение, и в некоторых указателях на неизвестный тип.

    **Пример:** `void print_status();` выполняет действие без результата.

    **Типичная ошибка:** Использовать `void` там, где вызывающему коду нужно сообщить успех или ошибку.

    **Источник:** [Cppreference: void type](https://en.cppreference.com/w/cpp/language/types)

83. Что значит передача аргумента по значению?

    **Ответ:** Функция получает отдельный параметр, и изменение этого параметра не меняет исходный объект вызывающего кода.

    **Пример:** `void increment(int value) { ++value; }` не изменяет переменную вызывающего кода.

    **Типичная ошибка:** Забыть стоимость копирования большого объекта и передавать его по значению без необходимости.

    **Источник:** [Cppreference: parameter passing](https://en.cppreference.com/w/cpp/language/function)

84. Что происходит с копией аргумента внутри функции?

    **Ответ:** Копия живёт как параметр функции, может изменяться локально и уничтожается при выходе из функции.

    **Пример:** `void set(int value) { value = 10; }` меняет только локальную копию.

    **Типичная ошибка:** Ожидать изменения оригинала без ссылки, указателя или другого явного механизма доступа.

    **Источник:** [Cppreference: parameter passing](https://en.cppreference.com/w/cpp/language/function)

85. Можно ли изменить исходную переменную, если параметр передан по значению?

    **Ответ:** Нет, изменение параметра по значению не изменяет исходный объект. Для этого нужна ссылка, указатель или возвращаемое значение.

    **Пример:** `void increment(int& value) { ++value; }` изменяет переданную переменную.

    **Типичная ошибка:** Использовать глобальное состояние вместо явного параметра-ссылки.

    **Источник:** [Cppreference: references](https://en.cppreference.com/w/cpp/language/reference)

86. Что такое перегрузка функций?

    **Ответ:** Перегрузка позволяет определить несколько функций с одним именем, но различающимися списками параметров.

    **Пример:** `int abs(int);` и `double abs(double);`.

    **Типичная ошибка:** Создавать перегрузки, которые неоднозначны после неявных преобразований.

    **Источник:** [Cppreference: function overload](https://en.cppreference.com/w/cpp/language/overload_resolution)

87. По каким признакам компилятор различает перегруженные функции?

    **Ответ:** Учитываются имя, количество, порядок и типы параметров, а также квалификаторы функций-членов; только возвращаемый тип не учитывается.

    **Пример:** `void print(int);` и `void print(std::string_view);` — разные перегрузки.

    **Типичная ошибка:** Пытаться различить функции только типом результата.

    **Источник:** [Cppreference: overload resolution](https://en.cppreference.com/w/cpp/language/overload_resolution)

88. Можно ли перегрузить функцию только по возвращаемому типу?

    **Ответ:** Нет. Вызов функции не содержит надёжного контекста для выбора только по возвращаемому типу.

    **Пример:** Нельзя одновременно объявить `int read();` и `double read();` в одной области.

    **Типичная ошибка:** Считать присваивание результата достаточным для разрешения такой перегрузки.

    **Источник:** [Cppreference: function overload](https://en.cppreference.com/w/cpp/language/overload_resolution)

89. Что такое рекурсия?

    **Ответ:** Рекурсия — вызов функцией самой себя прямо или через цепочку других функций.

    **Пример:** Рекурсивный обход дерева вызывает функцию для дочерних узлов.

    **Типичная ошибка:** Не доказать уменьшение задачи и условие остановки.

    **Источник:** [Cppreference: functions](https://en.cppreference.com/w/cpp/language/functions)

90. Что такое базовый случай в рекурсии?

    **Ответ:** Базовый случай — условие, при котором функция перестаёт делать рекурсивный вызов и возвращает результат напрямую.

    **Пример:** Для факториала `factorial(0)` возвращает `1`.

    **Типичная ошибка:** Проверять базовый случай после рекурсивного вызова и всё равно переполнять стек.

    **Источник:** [Cppreference: functions](https://en.cppreference.com/w/cpp/language/functions)

91. Чем опасна рекурсия без условия остановки?

    **Ответ:** Бесконечные вызовы обычно заканчиваются переполнением стека и аварийным завершением программы.

    **Пример:** `void loop() { loop(); }` не имеет достижимого базового случая.

    **Типичная ошибка:** Надеяться, что компилятор автоматически остановит рекурсию.

    **Источник:** [C++ Core Guidelines: recursion](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines)

92. Что такое массив?

    **Ответ:** Массив — объект, содержащий фиксированное число элементов одного типа, расположенных последовательно.

    **Пример:** `int values[3]{1, 2, 3};`.

    **Типичная ошибка:** Забывать размер массива и выходить за его границы.

    **Источник:** [Cppreference: array declaration](https://en.cppreference.com/w/cpp/language/array)

93. Как объявить одномерный массив?

    **Ответ:** Нужно указать тип элементов, имя и размер в квадратных скобках либо вывести размер из списка инициализации.

    **Пример:** `int values[3]{1, 2, 3};` или `int values[]{1, 2, 3};`.

    **Типичная ошибка:** Объявить локальный массив без инициализации и читать неинициализированные значения.

    **Источник:** [Cppreference: array declaration](https://en.cppreference.com/w/cpp/language/array)

94. Что такое индекс массива?

    **Ответ:** Индекс указывает позицию элемента в массиве и имеет целочисленный тип.

    **Пример:** В `values[0]` индекс `0` обозначает первый элемент.

    **Типичная ошибка:** Передать отрицательный или слишком большой индекс.

    **Источник:** [Cppreference: array](https://en.cppreference.com/w/cpp/language/array)

95. С какого индекса начинается массив в C++?

    **Ответ:** Индексация начинается с нуля, поэтому последний индекс массива размера `n` равен `n - 1`.

    **Пример:** Для `int values[3];` допустимы индексы `0`, `1` и `2`.

    **Типичная ошибка:** Использовать условие цикла `i <= n` вместо `i < n`.

    **Источник:** [Cppreference: array subscripting](https://en.cppreference.com/w/cpp/language/operator_member_access)

96. Что произойдёт при обращении за границы массива?

    **Ответ:** Для встроенного массива такое обращение приводит к неопределённому поведению.

    **Пример:** `values[3]` недопустим для массива из трёх элементов.

    **Типичная ошибка:** Проверять результат после выхода за границу: программа уже могла повредить память.

    **Источник:** [C++ Core Guidelines: bounds safety](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#bounds5-avoid-arrays-and-c-style-strings)

97. Что такое `std::string`?

    **Ответ:** `std::string` — стандартный владеющий тип для последовательности символов с управлением памятью и удобными операциями.

    **Пример:** `std::string name{"Ada"}; name += " Lovelace";`.

    **Типичная ошибка:** Возвращать `c_str()` и продолжать использовать указатель после изменения или уничтожения строки.

    **Источник:** [Cppreference: std::basic_string](https://en.cppreference.com/w/cpp/string/basic_string)

98. Чем `std::string` удобнее C-строки?

    **Ответ:** Он хранит размер, управляет памятью, поддерживает копирование и операции поиска/изменения без ручного `new` и `delete`.

    **Пример:** `text.size()` возвращает длину без обхода до нулевого символа.

    **Типичная ошибка:** Считать `std::string` совместимым с C API без явного получения `c_str()`.

    **Источник:** [Cppreference: std::basic_string](https://en.cppreference.com/w/cpp/string/basic_string)

99. Как считать строку с пробелами?

    **Ответ:** Используйте `std::getline`, потому что оператор `>>` останавливается на пробельном символе.

    **Пример:** `std::string line; std::getline(std::cin, line);`.

    **Типичная ошибка:** После `std::cin >> value` забыть обработать оставшийся перевод строки перед `getline`.

    **Источник:** [Cppreference: std::getline](https://en.cppreference.com/w/cpp/string/basic_string/getline)

100. Чем `cin >> str` отличается от `getline(cin, str)`?

     **Ответ:** `operator>>` пропускает начальные пробелы и читает до следующего пробела, а `getline` читает всю строку до разделителя, обычно `\n`.

     **Пример:** Для ввода `Ada Lovelace` `cin >> str` получит `Ada`, а `getline` — всю строку.

     **Типичная ошибка:** Смешивать эти операции без удаления оставшегося перевода строки.

     **Источник:** [Cppreference: std::getline](https://en.cppreference.com/w/cpp/string/basic_string/getline)

## Средний уровень

101. Что такое время жизни объекта?

     **Ответ:** Время жизни — период от завершения инициализации объекта до начала его уничтожения.

     **Пример:** Локальный объект живёт до выхода из блока, а динамический — до вызова `delete` или уничтожения владеющего умного указателя.

     **Типичная ошибка:** Путать время жизни объекта с областью видимости имени: объект может жить дольше, чем доступно его имя.

     **Источник:** [Cppreference: object lifetime](https://en.cppreference.com/w/cpp/language/lifetime)

102. Когда создаётся и уничтожается локальная переменная?

     **Ответ:** Локальная переменная с автоматическим временем хранения создаётся при достижении объявления и уничтожается при выходе из области блока в обратном порядке создания.

     **Пример:** `void f() { Logger logger; }` уничтожает `logger` при выходе из `f`.

     **Типичная ошибка:** Возвращать ссылку на локальную переменную после завершения функции.

     **Источник:** [Cppreference: storage duration](https://en.cppreference.com/w/cpp/language/storage_duration)

103. Что такое оператор `?:`?

     **Ответ:** Тернарный оператор выбирает второе или третье выражение в зависимости от условия и возвращает выбранный результат.

     **Пример:** `const char* state = ready ? "ready" : "wait";`.

     **Типичная ошибка:** Вкладывать несколько тернарных операторов и делать выражение труднее для чтения, чем обычный `if`.

     **Источник:** [Cppreference: conditional operator](https://en.cppreference.com/w/cpp/language/operator_other)

104. В каких случаях тернарный оператор удобнее `if/else`?

     **Ответ:** Он удобен для короткого выбора значения, когда обе ветви просты и выражение остаётся читаемым.

     **Пример:** `int sign = value < 0 ? -1 : 1;`.

     **Типичная ошибка:** Использовать тернарный оператор для нескольких действий или побочных эффектов.

     **Источник:** [C++ Core Guidelines: expressions](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#es6-avoid-complicated-expressions)

105. Что такое приоритет операторов?

     **Ответ:** Приоритет определяет, какие операторы группируются раньше при отсутствии скобок.

     **Пример:** `a + b * c` группируется как `a + (b * c)`.

     **Типичная ошибка:** Запоминать сложные правила вместо добавления скобок там, где намерение не очевидно.

     **Источник:** [Cppreference: operator precedence](https://en.cppreference.com/w/cpp/language/operator_precedence)

106. Почему выражение без скобок может дать неожиданный результат?

     **Ответ:** Компилятор применяет формальные приоритет и ассоциативность, которые могут отличаться от естественного прочтения человеком.

     **Пример:** `bool result = a || b && c;` означает `a || (b && c)`, а не `(a || b) && c`.

     **Типичная ошибка:** Писать условия с несколькими логическими операторами без явной группировки.

     **Источник:** [Cppreference: operator precedence](https://en.cppreference.com/w/cpp/language/operator_precedence)

107. Что такое ассоциативность операторов?

     **Ответ:** Ассоциативность определяет направление группировки операторов одного приоритета, обычно слева направо или справа налево.

     **Пример:** `a - b - c` группируется как `(a - b) - c`, а присваивание — справа налево.

     **Типичная ошибка:** Считать ассоциативность свойством порядка вычисления всех операндов.

     **Источник:** [Cppreference: operator precedence](https://en.cppreference.com/w/cpp/language/operator_precedence)

108. Чем отличаются префиксный и постфиксный инкремент?

     **Ответ:** Префиксный `++value` сначала увеличивает значение и возвращает уже изменённый результат, а постфиксный `value++` возвращает старое значение и увеличивает объект после этого.

     **Пример:** `int old = value++;` получает прежнее значение `value`.

     **Типичная ошибка:** Использовать постфиксную форму для сложного итератора без необходимости создавать временную копию.

     **Источник:** [Cppreference: increment operators](https://en.cppreference.com/w/cpp/language/operator_incdec)

109. В чём разница между `++i` и `i++`?

     **Ответ:** В отдельной инструкции обе формы увеличивают `i` на единицу, но значение самого выражения различается: `++i` — новое, `i++` — старое.

     **Пример:** `int a = ++i; int b = i++;` присваивают разные результаты.

     **Типичная ошибка:** Менять форму без понимания того, используется ли результат выражения.

     **Источник:** [Cppreference: increment operators](https://en.cppreference.com/w/cpp/language/operator_incdec)

110. Что такое неявное преобразование в выражениях?

     **Ответ:** Это автоматическое преобразование значения из одного типа в другой по правилам языка, например продвижение `char` к `int` или преобразование `int` к `double`.

     **Пример:** В `double ratio = 7 / 2.0;` целое `7` преобразуется к `double`.

     **Типичная ошибка:** Не замечать потерю данных при преобразовании `double` к `int` или переполнение при переходе к узкому типу.

     **Источник:** [Cppreference: implicit conversions](https://en.cppreference.com/w/cpp/language/implicit_conversion)
