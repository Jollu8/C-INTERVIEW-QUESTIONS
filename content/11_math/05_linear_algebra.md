# Линейная алгебра для работы с данными и вычислениями

Цель — понимать размерности, преобразования и разложения матриц, затем реализовывать и проверять вычисления. Предпосылки: арифметика, уравнения и индексация массивов; для сложных задач полезна тема численного представления. Здесь изучается математическая модель, а точность её реализации подробно разбирается в численных методах.

## Опорные понятия

- **Вектор** `x∈Rⁿ` — упорядоченные координаты. Для `x=(3,4)` евклидова норма `||x||₂=5`; направление единичного вектора — `(0.6,0.8)`.
- **Линейная комбинация** `a₁v₁+…+aₖvₖ` задаёт линейную оболочку. Базис — независимый набор, порождающий всё пространство; число его векторов равно размерности.
- **Скалярное произведение** вещественных векторов `xᵀy=Σxᵢyᵢ`. Нулевой результат означает ортогональность, но не означает, что один из векторов нулевой.
- **Матрица** `A∈Rᵐˣⁿ` преобразует `n` координат в `m`: `y=Ax`. Умножение `A(m×k)B(k×n)` даёт `C(m×n)`, где `Cᵢⱼ=ΣₗAᵢₗBₗⱼ`.
- **Ранг** — размерность образа. Для `A` с `n` столбцами `rank(A)+dim ker(A)=n`; система `Ax=b` совместна, когда `b` лежит в образе.
- **Ортогональная проекция** на ненулевой `v`: `p=v(vᵀx)/(vᵀv)`. Остаток `x-p` ортогонален `v`; МНК обобщает эту идею на подпространство столбцов.
- **Собственная пара** удовлетворяет `Av=λv`, `v≠0`. Для вещественной симметричной матрицы есть ортонормированный собственный базис; у произвольной матрицы его может не быть.
- **SVD** `A=UΣVᵀ` существует и у прямоугольной вещественной матрицы. Сингулярные числа неотрицательны; их малые значения показывают направления сильного сжатия. В комплексном случае используется сопряжённое транспонирование.

## Лёгкий уровень — основы

1. Что задают координаты вектора и почему длина массива не равна геометрической норме?

    **Ответ:** Координаты задают компоненты относительно выбранного базиса. У `(3,4)` две компоненты, но евклидова норма равна 5; число элементов и норма измеряют разные свойства. При смене базиса координаты могут измениться, хотя геометрический объект останется прежним. Норма тоже зависит от выбранной геометрии: формула корня суммы квадратов предполагает стандартный ортонормированный базис. В программе сначала проверяют размерность, а уже затем вычисляют выбранную меру длины.

    **Пример:** Для массива `[3,4]` операция `len` даёт 2. Геометрическая длина: `sqrt(3²+4²)=sqrt(25)=5`; расстояние от начала координат до точки `(3,4)` равно 5.

    **Источник:** [MIT 18.06, лекция 1: линейные уравнения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-1-the-geometry-of-linear-equations/).

2. Как сложить векторы и умножить вектор на число?

    **Ответ:** Операции выполняются покомпонентно: `(1,2)+(3,-1)=(4,1)`, `2(1,2)=(2,4)`. Складывать можно векторы одного пространства. Равенство размерностей важно: третью координату одного вектора нельзя молча отбросить из-за её отсутствия у другого. Умножение на отрицательное число меняет направление, на ноль даёт нулевой вектор. В реализации через списки нужно проверять длины до использования `zip`, который сам обрежет обход по короткому входу.

    **Источник:** [MIT 18.06, лекция 1: линейные уравнения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-1-the-geometry-of-linear-equations/).

3. Как вычислить скалярное произведение `(1,2,3)` и `(4,0,-1)`?

    **Ответ:** Суммировать произведения соответствующих координат: `4+0-3=1`. Это одно число, а покомпонентное умножение даёт вектор `(4,0,-3)`. Каждая пара координат вносит одно слагаемое в итоговую сумму; результат имеет скалярную размерность. В геометрии это произведение норм на косинус угла. В обработке данных так получают взвешенную сумму признаков, где второй вектор задаёт веса.

    **Типичная ошибка:** Смешивать скалярное произведение и поэлементное умножение массивов.

    **Пример:** Пары дают `1·4=4`, `2·0=0`, `3·(−1)=−3`. Сумма `4+0−3=1`; массив `[4,0,−3]` является промежуточным набором произведений, а не ответом на dot.

    **Источник:** [MIT 18.06, лекция 14: ортогональность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-14-orthogonal-vectors-and-subspaces/).

4. Как связаны нормы L1, L2 и L∞ с вектором ошибок?

    **Ответ:** Это соответственно сумма модулей, корень суммы квадратов и максимальный модуль. Для `(-3,4)` они равны 7, 5 и 4; выбор нормы задаёт смысл величины ошибки. L1 учитывает суммарную величину покомпонентных ошибок, L2 сильнее выделяет большие отклонения через квадрат, L∞ контролирует худшую компоненту. Нормы не взаимозаменяемы при задании требований: малое среднее отклонение не обеспечивает малого максимального. Единица каждой нормы вектора ошибок совпадает с единицей его компонент.

    **Пример:** Для ошибок `(−3,4)` L1 равна `3+4=7`, L2 — `sqrt(9+16)=5`, L∞ — `max(3,4)=4`. Если допустима ошибка не более 3 в каждом элементе, проверка L∞ выявит нарушение.

    **Источник:** [NumPy: линейная алгебра](https://numpy.org/doc/stable/reference/routines.linalg.html); [NumPy: определения векторных норм](https://numpy.org/doc/stable/reference/generated/numpy.linalg.norm.html).

5. Что обозначает размер матрицы `3×2`?

    **Ответ:** Три строки и два столбца. Такая матрица умножает двухкомпонентный столбец и возвращает трёхкомпонентный. Столбцы определяют число входных координат, строки — число выходных уравнений. Поэтому размеры матрицы уже задают интерфейс преобразования. В списке списков отдельно проверяют, что строки имеют одинаковую длину: рваный список прямоугольной матрицей не является.

    **Пример:** Для `A=[[1,0],[0,1],[1,1]]`, `x=(2,3)` получаем `(2,3,5)`. На входе две компоненты, на выходе три, хотя операция одна — умножение на A.

    **Источник:** [MIT 18.06, лекция 1: линейные уравнения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-1-the-geometry-of-linear-equations/).

6. Как определить размеры результата `A(2×3)B(3×4)`?

    **Ответ:** Внутренние размеры совпадают, результат имеет размер `2×4`. Каждая его компонента — произведение строки A на столбец B. Общий индекс перебирает три компоненты строки A и столбца B. Всего получится восемь элементов, каждый — сумма трёх произведений. Обратный порядок `BA` в данном случае вообще не определён, поскольку 4 не равно 2.

    **Пример:** Элемент с индексами `(0,2)` равен `A[0,0]B[0,2]+A[0,1]B[1,2]+A[0,2]B[2,2]`. Индексы строки и столбца результата сохраняются, суммируется только внутренний индекс.

    **Источник:** [NumPy: линейная алгебра](https://numpy.org/doc/stable/reference/routines.linalg.html); [NumPy: matmul и согласование размерностей](https://numpy.org/doc/stable/reference/generated/numpy.matmul.html).

7. Чем единичная матрица отличается от нулевой?

    **Ответ:** Единичная квадратная матрица имеет единицы на диагонали и сохраняет вектор при умножении; нулевая переводит любой вектор в нулевой. У единичной матрицы вне диагонали стоят нули. В выражениях `I_m A=A` и `A I_n=A` размеры единичных матриц могут различаться, если A прямоугольная. Нулевая матрица любого подходящего размера даёт нулевой результат, но сама не является нейтральным элементом умножения.

    **Источник:** [MIT 18.06, лекция 1: линейные уравнения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-1-the-geometry-of-linear-equations/).

8. Как транспонирование меняет размер и индексы матрицы?

    **Ответ:** `(Aᵀ)ᵢⱼ=Aⱼᵢ`, поэтому размер `m×n` меняется на `n×m`. Транспонирование — математическая операция; копируется ли память массива, зависит от представления. Исходная строка становится столбцом с теми же элементами. В NumPy транспонирование часто создаёт представление с другими strides, поэтому математически новая форма не гарантирует независимого буфера. Если нужна независимость дальнейших изменений, копирование следует запросить явно.

    **Пример:** У `[[1,2,3],[4,5,6]]` размер `2×3`, у транспонированной `[[1,4],[2,5],[3,6]]` — `3×2`. Элемент `A[1,2]=6` становится `A.T[2,1]=6`.

    **Источник:** [NumPy: линейная алгебра](https://numpy.org/doc/stable/reference/routines.linalg.html); [NumPy: transpose и представления](https://numpy.org/doc/stable/reference/generated/numpy.transpose.html).

9. Что означает линейная независимость двух векторов?

    **Ответ:** Равенство `av+bw=0` имеет только решение `a=b=0`. Например, `(1,0)` и `(0,1)` независимы, `(1,2)` и `(2,4)` зависимы. Достаточно одной ненулевой комбинации коэффициентов, дающей нулевой вектор, чтобы доказать зависимость. Для двух ненулевых векторов зависимость равносильна пропорциональности. Для трёх и более нельзя ограничиваться попарной проверкой пропорциональности.

    **Пример:** В R² векторы `(1,0)`, `(0,1)`, `(1,1)` попарно непропорциональны. Но первый плюс второй минус третий равен нулю, значит все три вместе зависимы.

    **Источник:** [MIT 18.06, лекция 9: базис и размерность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-9-independence-basis-and-dimension/).

10. Как вектор нормализуют и что делать с нулевым вектором?

    **Ответ:** Ненулевой x делят на `||x||₂`. Для нулевого вектора направление не определено: нужно вернуть ошибку, специальный результат или явно выбранное правило. Результат имеет единичную норму и сохраняет направление исходного вектора. Почти нулевой вектор тоже требует внимания: небольшая ошибка координат может сильно изменить направление. Порог отказа выбирают по масштабу входных данных и смыслу задачи.

    **Типичная ошибка:** Делить на нулевую норму и принимать NaN за направление.

    **Пример:** Для `(3,4)` сначала вычисляем норму 5, затем делим координаты: `(0.6,0.8)`. Проверка: `sqrt(0.36+0.64)=1`; для `(0,0)` такую последовательность выполнить нельзя.

    **Источник:** [MIT 18.06, лекция 14: ортогональность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-14-orthogonal-vectors-and-subspaces/).

## Средний уровень — применение

11. Почему матричное умножение в общем случае некоммутативно?

    **Ответ:** Оно описывает композицию преобразований, порядок которых влияет на результат; иногда BA вообще не определено. Например, поворот и растяжение вдоль одной оси обычно дают разные композиции. В записи `ABx` сначала действует B, затем A. Некоммутативность означает, что эти две последовательности преобразований обычно различаются даже при квадратных матрицах одного размера. В тесте реализации полезно иметь пример с `AB≠BA`, чтобы обнаружить переставленные индексы.

    **Пример:** Пусть `A=[[2,0],[0,1]]`, `B=[[0,−1],[1,0]]`. Тогда `AB=[[0,−2],[1,0]]`, а `BA=[[0,−1],[2,0]]`; на `(1,0)` результаты `(0,1)` и `(0,2)` различаются.

    **Источник:** [MIT 18.06, лекция 1: линейные уравнения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-1-the-geometry-of-linear-equations/).

12. Что означает `Ax` как комбинация столбцов A?

    **Ответ:** Компонента `xⱼ` — коэффициент при j-м столбце. Поэтому результат всегда лежит в линейной оболочке столбцов, даже если число строк больше числа столбцов. Это второй взгляд на ту же формулу, которая построчно вычисляет скалярные произведения. Он объясняет, почему множество достижимых правых частей системы совпадает с пространством столбцов. Число строк само по себе не означает, что любое значение каждой выходной координаты можно выбрать независимо.

    **Пример:** У `A=[[1,0],[0,1],[1,1]]` столбцы `(1,0,1)` и `(0,1,1)`. Для `x=(2,3)` их комбинация `2·(1,0,1)+3·(0,1,1)=(2,3,5)` всегда удовлетворяет `y₃=y₁+y₂`.

    **Источник:** [MIT 18.06, лекция 1: линейные уравнения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-1-the-geometry-of-linear-equations/).

13. Как ранг помогает определить, сколько независимых признаков содержится в данных?

    **Ответ:** Ранг равен максимальному числу линейно независимых столбцов или строк. Если один столбец точно выражается через другие, он не увеличивает ранг; при шуме нужен численный порог. Речь идёт о линейной информации: нелинейная связь признаков этим критерием полностью не описывается. В точной арифметике равенство комбинации проверяется точно, при измерениях нужно учитывать шум и единицы признаков. Масштабирование столбцов влияет на численную оценку ранга через порог.

    **Пример:** У столбцов `(1,2,3)` и `(2,4,6)` второй вдвое больше первого, ранг матрицы равен 1. Добавление столбца `(0,1,0)` повышает ранг до 2.

    **Источник:** [MIT 18.06, лекция 9: базис и размерность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-9-independence-basis-and-dimension/).

14. Когда система `Ax=b` имеет ноль, одно или бесконечно много решений?

    **Ответ:** Если b вне образа A, решений нет. Если b в образе, множество решений — `x₀+ker(A)`: решение единственно при нулевом ядре, иначе их бесконечно много над R. Ядро состоит из изменений неизвестных, которые A переводит в ноль. Поэтому к любому одному решению можно прибавить вектор ядра и получить другое решение той же системы. Для прямоугольной матрицы единственность требует полного столбцового ранга, но совместность с конкретным b всё равно проверяется отдельно.

    **Пример:** Уравнение `x+y=2` имеет решения `(t,2−t)` для любого вещественного t. Пара уравнений `x+y=2`, `2x+2y=5` несовместна: левая часть второго обязана вдвое превосходить первую.

    **Источник:** [MIT 18.06, лекция 9: базис и размерность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-9-independence-basis-and-dimension/).

15. Когда квадратная матрица обратима?

    **Ответ:** Когда её ранг равен размеру, ядро нулевое, а определитель ненулевой. Обратимость — точное математическое свойство; близость к вырожденности оценивают отдельно. Эти критерии эквивалентны над точными вещественными числами. На компьютере вычисленный ненулевой определитель не обещает приемлемой точности решения. Если нужна правая часть конкретной системы, предпочтительнее решать систему и оценивать остаток с обусловленностью.

    **Источник:** [NumPy: linalg.solve](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html).

16. Почему для решения `Ax=b` предпочитают solve вычислению `inv(A) @ b`?

    **Ответ:** Разложение и подстановки решают задачу непосредственно, обычно с меньшей работой и без формирования всех элементов обратной матрицы. Обратная матрица сама по себе может быть нужна в другой задаче. У общей плотной матрицы разложение требует порядка n³ операций, а решение для новой правой части после сохранённого разложения — порядка n². Построение обратной матрицы фактически решает систему сразу для многих правых частей, даже если нужна одна. Для серии правых частей повторно используют разложение или передают их матрицей.

    **Типичная ошибка:** Явно обращать матрицу для каждой новой правой части.

    **Пример:** Для `A=[[2,1],[1,−1]]`, `b=(5,1)` вызов `solve(A,b)` непосредственно ищет `(2,1)`. Проверяется `A·(2,1)=(5,1)`; хранить все четыре элемента обратной матрицы для этой задачи не требуется.

    **Источник:** [NumPy: linalg.solve](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html).

17. Как проверить ортогональность двух ненулевых вещественных векторов?

    **Ответ:** Проверить `xᵀy=0`; для вычислений задать допуск относительно масштабов `||x||·||y||`. Для `(1,1)` и `(1,-1)` произведение равно нулю. При floating point удобно сравнить `abs(xᵀy)` с `tol·||x||₂·||y||₂`, если оба вектора ненулевые. Это проверяет малость косинуса угла и учитывает масштаб. Нулевой вектор ортогонален любому в алгебраическом смысле, но угол с ним не определён.

    **Источник:** [MIT 18.06, лекция 14: ортогональность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-14-orthogonal-vectors-and-subspaces/).

18. Как получить проекцию `(2,3)` на прямую вдоль `(1,1)`?

    **Ответ:** Коэффициент равен `(2+3)/(1+1)=2.5`, проекция `(2.5,2.5)`, остаток `(-0.5,0.5)` ортогонален направлению. Проекция выбирает ближайшую к x точку на прямой. Коэффициент найден из условия ортогональности остатка направляющему вектору: `(x−αv)ᵀv=0`. Деление на `vᵀv` допустимо только для ненулевого v.

    **Пример:** Здесь `xᵀv=5`, `vᵀv=2`, значит `α=2.5`. Проверяем остаток: `−0.5·1+0.5·1=0`; его квадрат длины равен 0.5, что меньше, чем у любого смещения по прямой от точки проекции.

    **Источник:** [MIT 18.06, лекция 16: проекции и МНК](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-16-projection-matrices-and-least-squares/).

19. Что минимизирует метод наименьших квадратов в переопределённой системе?

    **Ответ:** Квадрат евклидовой нормы остатка `||Ax-b||₂²`. Минимизатор удовлетворяет `Aᵀ(Ax-b)=0`; единственность требует полного столбцового ранга. Остаток в оптимуме ортогонален каждому столбцу A: движение решения вдоль любого столбца уже не уменьшает сумму квадратов в первом порядке. При недостаточном ранге минимум остаётся, но коэффициенты могут быть неединственны. Даже при единственном решении отдельные компоненты остатка обычно не равны нулю.

    **Пример:** Для приближения точек `(0,1),(1,2),(2,2)` прямой матрица имеет строки `(1,0),(1,1),(1,2)`. Два коэффициента не могут точно удовлетворить трём несовместным уравнениям, поэтому минимизируется суммарная ошибка, а не выбираются любые два уравнения.

    **Источник:** [MIT 18.06, лекция 16: проекции и МНК](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-16-projection-matrices-and-least-squares/).

20. Что выражает QR-разложение и как оно помогает МНК?

    **Ответ:** Тонкое разложение `A=QR` для полного столбцового ранга даёт ортонормированные столбцы Q и верхнетреугольную R. Решают `Rx=Qᵀb`, не формируя `AᵀA`. Здесь предполагаются `m≥n` и независимые столбцы A. Ортогональность Q позволяет отделить часть b в пространстве столбцов, после чего остаётся треугольная система. При вырожденности нужны дополнительные приёмы, например QR с выбором столбцов или SVD.

    **Пример:** Если `A=[[1,0],[0,2],[0,0]]`, можно взять `Q=[[1,0],[0,1],[0,0]]`, `R=diag(1,2)`. Для `b=(3,4,5)` решаем `Rx=(3,4)` и получаем `(3,2)`; третью компоненту 5 воспроизвести невозможно.

    **Источник:** [NumPy: linalg.lstsq](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html).

21. Как проверить собственный вектор для диагональной матрицы `diag(2,5)`?

    **Ответ:** Векторы `(1,0)` и `(0,1)` имеют собственные значения 2 и 5. Проверка любой предложенной пары — вычислить остаток `Av-λv`. Нулевой вектор не является собственным, поскольку равенство выполнялось бы с ним для любого λ и ничего не выделяло. У вычисленной пары проверяют относительную величину остатка с учётом масштаба A и v. Одна лишь близость найденного λ к ожидаемому числу не проверяет вектор.

    **Источник:** [MIT 18.06, лекция 21: собственные значения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-21-eigenvalues-and-eigenvectors/).

22. Что означает положительная определённость симметричной матрицы?

    **Ответ:** Для любого ненулевого x выполнено `xᵀAx>0`. Все её собственные значения положительны; это обеспечивает единственный минимум соответствующей строго выпуклой квадратичной функции. Симметричность здесь существенна для связи с положительными собственными значениями. Квадратичная форма `xᵀAx` задаёт положительную кривизну во всех ненулевых направлениях. Проверка только положительных диагональных элементов недостаточна.

    **Пример:** У `A=[[1,2],[2,1]]` обе диагонали положительны. Но для `x=(1,−1)` получаем `xᵀAx=−2`, поэтому положительной определённости нет.

    **Источник:** [MIT 18.06, лекция 25: положительная определённость](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-25-symmetric-matrices-and-positive-definiteness/).

23. Как собственные и сингулярные числа отличаются по области применимости?

    **Ответ:** Собственные значения определяются у квадратной матрицы и могут быть комплексными. Сингулярные числа существуют и у прямоугольной, вещественны и неотрицательны; это корни собственных значений `AᵀA`. Для вещественной симметричной матрицы сингулярные числа равны модулям собственных значений, но для произвольной матрицы это правило неверно. Сингулярные числа описывают растяжение длины и подходят для оценки норм и обусловленности. Собственные значения описывают направления, сохраняемые самим преобразованием.

    **Пример:** У `diag(−3,2)` собственные значения `−3,2`, а сингулярные числа `3,2`. У матрицы поворота на 90° вещественных собственных направлений нет, однако оба сингулярных числа равны 1.

    **Источник:** [MIT 18.06, лекция 29: SVD](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-29-singular-value-decomposition/).

24. Что делает переход от координат к новому базису B?

    **Ответ:** Если столбцы обратимой B — новый базис в старых координатах, то `x_old=B x_new`, `x_new=B⁻¹x_old`. Порядок умножения задаётся направлением преобразования. Вычислять явную обратную обычно необязательно: достаточно решить `B x_new=x_old`. Меняется представление объекта, а не сам объект. Если нужен оператор A в новых координатах, он записывается как `B⁻¹AB`.

    **Пример:** Пусть столбцы `B=[[1,1],[0,1]]` — новые базисные векторы. Для старых координат `(3,1)` получаем новые `(2,1)`, поскольку `2·(1,0)+1·(1,1)=(3,1)`.

    **Источник:** [MIT 18.06, лекция 9: базис и размерность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-9-independence-basis-and-dimension/).

25. Каково скалярное произведение комплексных векторов и зачем нужно сопряжение?

    **Ответ:** Обычное эрмитово произведение `xᴴy=Σconj(xᵢ)yᵢ` обеспечивает `xᴴx=Σ|xᵢ|²≥0`. Без сопряжения `(i)ᵀ(i)=-1`, что не является квадратом нормы. Сопряжение меняет знак мнимой части первой компоненты; в некоторых учебниках принято сопрягать второй аргумент, поэтому соглашение нужно указывать. Для нормы оба соглашения дают один положительный результат. В NumPy `vdot` сопрягает первый аргумент, а обычный `dot` этого не делает.

    **Типичная ошибка:** Использовать обычное транспонирование вместо сопряжённого при комплексных данных.

    **Пример:** Для `x=(1+i,2)` квадрат нормы равен `(1−i)(1+i)+2·2=2+4=6`. Если перемножить x с собой без сопряжения, получится `(1+i)²+4=4+2i`, что не является квадратом вещественной длины.

    **Источник:** [MIT 18.06, лекция 14: ортогональность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-14-orthogonal-vectors-and-subspaces/); [NumPy: vdot и сопряжение первого аргумента](https://numpy.org/doc/stable/reference/generated/numpy.vdot.html).

## Сложный уровень — обоснование и ограничения

26. Почему малый определитель сам по себе не доказывает плохую обусловленность?

    **Ответ:** Определитель меняется при масштабировании: у `10⁻⁶I` он очень мал, но отношение максимального и минимального сингулярных чисел равно 1. Для чувствительности решаемой системы используют число обусловленности. Определитель — произведение масштабов по направлениям, а обусловленность сравнивает их максимальное и минимальное значения. Малое общее масштабирование уменьшает определитель, не ухудшая это отношение. Напротив, большой разброс масштабов может дать определитель порядка единицы при огромной обусловленности.

    **Типичная ошибка:** Сравнивать определитель с универсальным epsilon независимо от масштаба.

    **Пример:** Для `diag(10⁶,10⁻⁶)` определитель равен 1, но `κ₂=10¹²`. Для `10⁻⁶I₂` определитель `10⁻¹²`, а `κ₂=1`: универсальный порог определителя перепутает эти случаи.

    **Источник:** [NumPy: linalg.cond](https://numpy.org/doc/stable/reference/generated/numpy.linalg.cond.html).

27. Почему формирование нормальных уравнений может ухудшить точность МНК?

    **Ответ:** При полном столбцовом ранге `κ₂(AᵀA)=κ₂(A)²`. Округление может сделать почти зависимые столбцы неразличимыми; QR или SVD обычно сохраняют больше информации. Числа σ² появляются потому, что собственные значения `AᵀA` равны квадратам сингулярных чисел A. Поэтому направления, уже плохо различимые в A, становятся ещё труднее различимыми после образования произведения. Дополнительно округляются сами элементы `AᵀA`; хороший алгоритм решения полученной системы не восстанавливает утраченную информацию.

    **Пример:** Если `κ₂(A)=10⁶`, у нормальной матрицы оно `10¹²`. Это не обещает точное число потерянных цифр для любого b, но показывает, почему QR/SVD предпочтительнее при почти зависимых признаках.

    **Источник:** [NumPy: linalg.lstsq](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html).

28. Как SVD задаёт численный ранг и почему нужен порог?

    **Ответ:** Считают сингулярные числа выше выбранного порога относительно масштаба и ошибки данных. Точный ранг может измениться от сколь угодно малого возмущения, поэтому порог зависит от задачи. Для `diag(1,10⁻¹²)` точный ранг равен 2. Если второй масштаб меньше неопределённости данных, трактовать его как надёжное независимое направление нельзя. Порог обычно задают через относительную ошибку и максимальное сингулярное число; машинный epsilon сам по себе не описывает шум измерений.

    **Пример:** При пороге `10⁻¹⁰` указанная матрица имеет численный ранг 1, при `10⁻¹⁴` — 2. В отчёте полезно хранить сами сингулярные числа и выбранный порог, а не только целое значение ранга.

    **Источник:** [NumPy: linalg.svd](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html).

29. Что даёт псевдообратная для несовместной или недоопределённой системы?

    **Ответ:** Она выбирает среди решений МНК решение минимальной евклидовой нормы. SVD обращает только оставленные ненулевые сингулярные числа; порог влияет на результат. Если система совместна и недоопределена, выбирается решение без лишней компоненты в ядре A. Если несовместна, сначала минимизируется остаток, затем среди минимизаторов выбирается минимальная норма. Отбрасывание ненулевых малых σ является усечением: оно уже меняет точную псевдообратную и вводит регуляризацию.

    **Пример:** Для `[1,1]x=2` все решения `(1+t,1−t)` имеют квадрат нормы `2+2t²`. Псевдообратная выбирает t=0, то есть `(1,1)`.

    **Источник:** [MIT 18.06, лекция 29: SVD](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-29-singular-value-decomposition/).

30. Почему не всякая матрица диагонализуема?

    **Ответ:** Нужен полный базис собственных векторов. У `[[1,1],[0,1]]` собственное значение 1 кратности 2, но пространство собственных векторов одномерно. Для диагонализации `A=VΛV⁻¹` столбцы V должны образовать базис. Алгебраическая кратность корня характеристического многочлена не гарантирует столько же независимых собственных векторов. У симметричной вещественной матрицы такого препятствия нет: существует ортонормированный собственный базис.

    **Пример:** У указанной матрицы `(A−I)v=0` требует `v₂=0`, оставляя только направление `(1,0)`. Двух независимых столбцов для V не набирается, хотя собственное значение посчитано два раза.

    **Источник:** [MIT 18.06, лекция 21: собственные значения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-21-eigenvalues-and-eigenvectors/).

31. Когда степенной метод может не выделить нужный собственный вектор?

    **Ответ:** Нужны, в типичном случае, единственное по модулю доминирующее собственное значение и ненулевая начальная компонента вдоль его направления. При равных модулях возможны колебания; проверяют остаток, а не только норму итерата. Для симметричной матрицы это удобно понять разложением начального вектора по собственному базису: после k шагов коэффициенты умножатся на `λᵢᵏ`. Нормирование убирает общий рост, но не создаёт отсутствующую компоненту. Если доминирующее значение отрицательно, знак итерата может чередоваться даже при сходимости направления.

    **Пример:** Для `diag(4,1)` старт `(0,1)` всегда остаётся на второй оси и даёт λ=1. Старт `(1,1)` ведёт к первой оси, поскольку отношение второй компоненты к первой умножается на 1/4.

    **Источник:** [MIT 18.06, лекция 21: собственные значения](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-21-eigenvalues-and-eigenvectors/).

32. Как связать ошибку приближения матрицей ранга k с сингулярными числами?

    **Ответ:** Усечённая SVD оптимальна в спектральной и фробениусовой нормах. Ошибки равны `σₖ₊₁` и корню суммы квадратов отброшенных сингулярных чисел соответственно. Здесь приближения рассматриваются среди всех матриц ранга не выше k. Спектральная норма измеряет наибольшую ошибку действия на единичный вектор, фробениусова — суммарную квадратичную ошибку элементов. При совпадении граничных сингулярных чисел оптимальное приближение может быть неединственным.

    **Пример:** У `diag(5,3,1)` после сохранения одного направления остаются σ=3 и 1. Спектральная ошибка равна 3, фробениусова — `sqrt(9+1)=sqrt(10)`.

    **Источник:** [MIT 18.06, лекция 29: SVD](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-29-singular-value-decomposition/).

33. Почему знак отдельного собственного или сингулярного вектора нельзя сравнивать с эталоном буквально?

    **Ответ:** Вектор и его отрицание описывают одно направление; при кратных значениях можно менять базис соответствующего подпространства. Сравнивают остатки, проекторы и восстановление матрицы. Для собственной пары `A(−v)=λ(−v)` выполняется с тем же λ. В SVD знак левого и соответствующего правого вектора меняют одновременно, сохраняя их внешнее произведение. При комплексных данных аналогичная свобода выражается фазовым множителем единичного модуля.

    **Пример:** Если один алгоритм вернул `(1,1)/sqrt(2)`, а другой `(-1,-1)/sqrt(2)`, это одно направление. Сравнение `||v−w||` ошибочно сообщит большое отличие; лучше проверить `min(||v−w||,||v+w||)` или проекторы `vvᵀ`, `wwᵀ`.

    **Источник:** [NumPy: linalg.svd](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html).

34. Как layout и порядок обхода влияют на матричное умножение, сохраняя его математический смысл?

    **Ответ:** Меняются локальность и повторное использование данных; блоки позволяют сократить обращения к памяти. Перестановка суммирований в floating point может менять младшие разряды, поэтому проверяют допуск, а производительность измеряют отдельно. Для row-major массива последовательный обход соседних столбцов одной строки обычно использует локальность лучше, чем шаги через строки. Блочная версия удерживает небольшие части A, B и C в близкой памяти и повторно использует загруженные элементы. Но скорость зависит от языка, библиотеки, размеров и оборудования: ускорение нужно измерить.

    **Пример:** Один и тот же `C[i,j]=Σₖ A[i,k]B[k,j]` можно считать порядком i-j-k или блоками по 16. На небольших целых числах при достаточном накопителе результаты одинаковы, а у floating point новый порядок сложений может изменить последние биты.

    **Источник:** [NumPy: линейная алгебра](https://numpy.org/doc/stable/reference/routines.linalg.html).

35. Как регуляризация `||Ax-b||²+λ||x||²` меняет плохо определяемые направления?

    **Ответ:** При `λ>0` сингулярное направление получает коэффициент `σ/(σ²+λ)` вместо `1/σ`; малые σ меньше усиливают шум. Это вводит смещение и меняет исходную задачу. Из производной целевой функции получают `(AᵀA+λI)x=Aᵀb`. В SVD-базисе каждое направление решается независимо, откуда и возникает указанный множитель. λ выбирают с учётом масштаба признаков и допустимого смещения; одна величина λ не переносится автоматически на произвольно масштабированные данные.

    **Пример:** Для скалярной A=0.001 и b=1 обычное решение x=1000. При λ=0.01 получаем `x=0.001/(0.000001+0.01)≈0.09999`: усиление подавлено, но исходное уравнение уже не решается точно.

    **Источник:** [MIT 18.06, лекция 29: SVD](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-29-singular-value-decomposition/).

36. Напишите dot для двух массивов `[1,2,3]`, `[4,0,-1]`; определите поведение для пустых и разных длин.

    **Ответ:** Накопить сумму произведений, получить 1. Для двух пустых массивов естественный результат 0; несовпадение длин отклонить до вычислений. Сначала проверяются длины, затем аккумулятор обнуляется, и для каждого индекса к нему прибавляется одно произведение. В Python с целыми такой пример вычисляется точно; в C++ тип произведения и накопителя должны вмещать промежуточные значения. Пустая сумма равна нулю, что делает поведение совместимым с алгебраическими свойствами.

    **Проверка:** Проверьте результат 1, пустые входы, несовпадение длин и линейность на небольших целых числах без переполнения.

    **Пример:** Шаги накопителя: `0→4→4→1`. Для проверки линейности возьмите ещё `z=(1,1,1)` и убедитесь, что `dot(x+z,y)=dot(x,y)+dot(z,y)=4`.

    ```python
    def dot(x, y):
        if len(x) != len(y):
            raise ValueError("different vector lengths")
        total = 0
        for i in range(len(x)):
            total += x[i] * y[i]
        return total

    assert dot([1, 2, 3], [4, 0, -1]) == 1
    assert dot([], []) == 0
    ```

    **Источник:** [MIT 18.06, лекция 14: ортогональность](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-14-orthogonal-vectors-and-subspaces/).

39. Умножьте A=`[[1,2,3],[4,5,6]]` на B=`[[1,0],[0,1],[1,1]]`; напишите прямой тройной цикл.

    **Ответ:** Результат `[[4,5],[10,11]]`. Выделить `2×2` результата и суммировать по общему индексу от 0 до 2. Столбцы B равны `(1,0,1)` и `(0,1,1)`. Поэтому первая строка результата равна `(1+3,2+3)`, вторая `(4+6,5+6)`. В тройном цикле суммируют по k при фиксированных i,j; аккумулятор обнуляют для каждого нового элемента C.

    **Проверка:** Сравните с эталоном, `AI=A` для подходящего I и случайными малыми матрицами в NumPy.

    **Пример:** Чтобы обнаружить ошибку с обнулением аккумулятора, выведите четыре отдельные суммы: `1+0+3`, `0+2+3`, `4+0+6`, `0+5+6`. Ожидаются 4, 5, 10, 11.

    ```python
    def matmul(a, b):
        # Контракт этого примера: непустые прямоугольные матрицы.
        if not a or not b or not a[0] or not b[0]:
            raise ValueError("empty matrix")
        m, shared, n = len(a), len(a[0]), len(b[0])
        if any(len(row) != shared for row in a):
            raise ValueError("ragged first matrix")
        if len(b) != shared or any(len(row) != n for row in b):
            raise ValueError("incompatible matrix shapes")
        c = [[0 for _ in range(n)] for _ in range(m)]
        for i in range(m):
            for j in range(n):
                for k in range(shared):
                    c[i][j] += a[i][k] * b[k][j]
        return c

    assert matmul([[1, 2, 3], [4, 5, 6]], [[1, 0], [0, 1], [1, 1]]) == [[4, 5], [10, 11]]
    ```

    **Источник:** [NumPy: линейная алгебра](https://numpy.org/doc/stable/reference/routines.linalg.html); [NumPy: matmul](https://numpy.org/doc/stable/reference/generated/numpy.matmul.html).
