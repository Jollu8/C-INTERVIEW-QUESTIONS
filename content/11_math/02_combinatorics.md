# Комбинаторика и подсчёт вариантов

Цель — оценивать пространство состояний, объём перебора и число способов построить объект. Предпосылки: множества, логика, целые числа и циклы. C(n,k) означает число k-элементных подмножеств n-элементного множества; n и k — неотрицательные целые. В задачах сначала сформулируйте, что считается одним вариантом, затем считайте.

## Опорные понятия

- **Правило суммы.** Непересекающиеся варианты складываются. Если команды выбираются из двух непересекающихся наборов по 3 и 5, всего 8 вариантов; при пересечении общие варианты нужно учесть один раз.
- **Правило произведения.** Если для каждого выбора первого шага доступно одинаковое число вариантов следующего шага, количества перемножаются. Для 3 платформ, 2 компиляторов и 4 режимов получается 24 конфигурации.
- **Порядок и повторения.** Строка AB отличается от BA, множество {A,B} совпадает с {B,A}. Упорядоченных выборов k различных элементов из n: n(n−1)…(n−k+1); неупорядоченных — C(n,k)=n!/(k!(n−k)!).
- **Пустые объекты.** Пустая последовательность существует в одном варианте: 0!=1 и C(n,0)=1. Это согласует рекуррентные формулы с базовыми случаями динамического программирования.
- **Биты и подмножества.** Каждому из n элементов соответствует решение «включить / исключить», поэтому подмножеств 2ⁿ, а с ровно k элементами — C(n,k).
- **Суммы.** 1+…+n=n(n+1)/2; 1+2+…+2ⁿ⁻¹=2ⁿ−1. Эти формулы помогают считать пары, вложенные циклы и узлы деревьев перебора.
- **Дирихле и включения-исключения.** n+1 объектов в n ячейках дают совпадение; |A∪B|=|A|+|B|−|A∩B| устраняет двойной счёт. Для трёх множеств тройное пересечение возвращают после вычитания парных.
- **Подсчёт в программе.** Ответ может быть значительно больше входа: C(64,32) уже очень велико. Различайте число математических объектов, стоимость получения одного объекта и память для хранения всех результатов.

## Лёгкий уровень — основы

1. Когда количество вариантов складывают, а когда перемножают?

   **Ответ:** Сложение подходит для альтернативных непересекающихся случаев. Умножение — для последовательных выборов с известным количеством продолжений каждого частичного выбора. Важно считать одинаковые конечные объекты одинаково на всех шагах. Например, один из 3 текстовых или 2 бинарных форматов даёт 5 форматов, а формат вместе с одним из 4 режимов даёт 20 пар.

   **Типичная ошибка:** Складывать мощности пересекающихся наборов без вычитания общих объектов.

   **Источник:** [MIT MCS, гл. 14.1–14.2: правила подсчёта](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session25/)

2. Сколько разных конфигураций дают 3 ОС, 2 компилятора и 4 режима сборки без ограничений совместимости?

   **Ответ:** По правилу произведения 3·2·4=24. Каждая конфигурация — упорядоченная тройка, так что позиции имеют разные роли. Если часть сочетаний несовместима, 24 становится числом всех кандидатов, а допустимые нужно считать отдельно.

   **Источник:** [MIT MCS, гл. 14.1–14.2: правила подсчёта](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session25/)

3. Что означает факториал n! и почему 0!=1?

   **Ответ:** n! — произведение целых от 1 до n и число перестановок n различных объектов. Пустой набор можно упорядочить ровно одним способом: ничего не разместить. Значение 0!=1 сохраняет формулу n!=n·(n−1)! и корректные базы для подсчёта.

   **Пример:** Для трёх разных задач A,B,C первую можно выбрать тремя способами, вторую двумя, последнюю одним: 3·2·1=6 порядков. При переходе к пустому набору остаётся один результат — пустой порядок, а не отсутствие допустимых результатов. Поэтому генератор перестановок пустой коллекции должен выдать одну пустую последовательность.

   **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

4. Чем перестановка всех элементов отличается от выбора подмножества?

   **Ответ:** Перестановка задаёт порядок всех элементов; подмножество задаёт только состав. Для {A,B,C} перестановок 6, а двухэлементных подмножеств 3. Перестановки AB и BA различны, но соответствуют одному подмножеству {A,B}.

   **Типичная ошибка:** Применять n! там, где порядок не входит в результат задачи.

   **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

5. Сколько двоичных строк длины n и что происходит при n=0?

   **Ответ:** В каждой из n позиций два независимых выбора, значит 2ⁿ строк. При n=0 существует одна пустая строка. Число строк не равно памяти для их перечисления: запись каждой непустой строки требует ещё n бит или символов.

   **Источник:** [MIT MCS, гл. 14.1–14.2: правила подсчёта](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session25/)

6. Что считает C(n,k)?

   **Ответ:** Это количество k-элементных подмножеств n различных элементов без учёта порядка. Для 0≤k≤n формула равна n!/(k!(n−k)!). При k>n обычно полагают C(n,k)=0, поскольку выбрать больше различных элементов нельзя.

   **Пример:** Из четырёх серверов A,B,C,D выбираем пару резервов. Получаем AB,AC,AD,BC,BD,CD — шесть наборов. Упорядоченных пар было бы 4·3=12, но каждый набор встречается в двух порядках: C(4,2)=12/2=6.

   **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

7. Почему C(n,k)=C(n,n−k)?

   **Ответ:** Каждому выбранному k-подмножеству соответствует его дополнение из n−k элементов. Это взаимно однозначное соответствие, и оно сохраняет количество объектов. Например, выбрать 2 исключения из 7 так же сложно по числу вариантов, как выбрать 5 оставляемых: 21 способ.

   **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

8. Сколько непустых подмножеств содержит множество из 5 элементов?

   **Ответ:** Всего подмножеств 2⁵=32, включая пустое. Удаляем ровно один пустой вариант и получаем 31. При n=0 эта же формула 2⁰−1 даёт 0, что соответствует смыслу задачи.

   **Источник:** [MIT MCS, гл. 14.1–14.2: правила подсчёта](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session25/)

9. Чем выбор с возвращением отличается от выбора без возвращения?

   **Ответ:** При возвращении элемент доступен на следующих шагах снова. Без возвращения количество доступных различных элементов уменьшается. Для двух упорядоченных выборов из трёх объектов получаем соответственно 3²=9 и 3·2=6 вариантов.

   **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

10. Сколько неупорядоченных пар разных элементов среди n объектов?

    **Ответ:** Выбираем 2 из n: C(n,2)=n(n−1)/2. Деление на 2 убирает две записи каждой пары, (a,b) и (b,a). Для n=0 или n=1 пар нет; диагональные пары здесь исключены.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

## Средний уровень — применение

11. Как посчитать число строк длины 4 из 10 цифр, если первая цифра не может быть нулём?

    **Ответ:** Для первой позиции 9 вариантов, для каждой следующей — 10, всего 9·10³=9000. Повтор цифр разрешён, поскольку запрета нет. Если речь об идентификаторе, а не четырёхзначном числе, ограничение первой цифры нужно явно обосновать.

    **Пример:** При первом символе 7 оставшиеся три позиции образуют строки 7000…7999 — 1000 вариантов. Таких допустимых первых символов девять, и группы не пересекаются, поэтому 9·1000=9000. Если запретить повтор цифр, продолжения станут 9,8,7 вместо 10,10,10, и ответ изменится на 9·9·8·7=4536.

    **Источник:** [MIT MCS, гл. 14.1–14.2: правила подсчёта](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session25/)

12. Сколько строк длины 4 из {A,B,C,D,E} без повторов?

    **Ответ:** Это упорядоченный выбор: 5·4·3·2=120. После каждой позиции один символ исключается. Делить на 4! нельзя, потому что разные порядки символов дают разные строки.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

13. Как посчитать перестановки строки AABC?

    **Ответ:** Если временно различить две A, получится 4!=24 перестановки. Каждая настоящая строка учтена 2! раза из-за обмена одинаковых A. Поэтому различных строк 4!/2!=12; общий знаменатель содержит факториалы всех кратностей.

    **Пример:** В слове AABB временно обозначим одинаковые символы A₁,A₂ и B₁,B₂: есть 4!=24 перестановки. Каждая строка AABB, ABAB и остальные записывается 2!·2!=4 способами смены меток. Поэтому разных строк 24/4=6; делить только на 2!, учитывая лишь повторы A, было бы недостаточно.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

14. Сколько способов выбрать два элемента с повторениями из трёх типов без учёта порядка?

    **Ответ:** Нужно посчитать неотрицательные решения x₁+x₂+x₃=2. Метод разделителей даёт C(2+3−1,3−1)=C(4,2)=6. Варианты: AA,AB,AC,BB,BC,CC; BA отдельно не учитывается.

    **Пример:** Пусть xA+xB+xC=2. Пара AA кодируется двумя звёздочками перед обоими разделителями: `**||`; пара AC — `*||*`. В строке из двух звёздочек и двух разделителей нужно выбрать две позиции разделителей из четырёх. Это даёт C(4,2)=6 и объясняет, почему пустые группы допустимы.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

15. Как вывести рекуррентное равенство Паскаля C(n,k)=C(n−1,k−1)+C(n−1,k)?

    **Ответ:** Зафиксируйте один элемент. Подмножества, содержащие его, требуют ещё k−1 элементов из n−1; остальные требуют k из n−1. Эти два случая непересекаются и покрывают все варианты, поэтому количества складываются.

    **Пример:** Чтобы получить C(5,2), выделим элемент E. Пары с E: AE,BE,CE,DE — C(4,1)=4; пары без E — C(4,2)=6. Сумма 4+6=10 даёт следующий элемент треугольника Паскаля и показывает, какие результаты объединяет рекуррентная формула.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

16. Почему сумма всех C(n,k) при k=0…n равна 2ⁿ?

    **Ответ:** Слева все подмножества разбиты по размеру, и каждое попало ровно в одну группу. Справа те же объекты посчитаны решениями «включить / исключить» для каждого элемента. Равенство полезно как проверка строки треугольника Паскаля.

    **Пример:** Строка Паскаля для n=4: 1,4,6,4,1. Группы соответствуют подмножествам размеров 0,1,2,3,4 и в сумме дают 16. Если в программе сумма вышла 15, часто потерян пустой набор или неправильно задана база C(n,0).

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

17. Сколько операций выполняют циклы i=0…n−1 и j=i+1…n−1?

    **Ответ:** Каждая итерация внутреннего цикла соответствует паре индексов i<j. Таких пар C(n,2)=n(n−1)/2. Это Θ(n²), хотя внутренний цикл имеет переменную длину; при n=4 точное число равно 6.

    **Пример:** Для n=4 внутренний цикл выполняется 3,2,1,0 раз. Сумма 3+2+1+0=6 соответствует парам (0,1),(0,2),(0,3),(1,2),(1,3),(2,3). Цикл по всем i и j с условием i!=j выполнит тело 12 раз: он учитывает оба порядка одной неупорядоченной пары.

    **Источник:** [MIT MCS, гл. 13.1–13.5: суммы](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session23/)

18. Как геометрическая сумма оценивает полный двоичный перебор глубины d?

    **Ответ:** На уровне i полного двоичного дерева 2ⁱ узлов. При уровнях 0…d всего 1+2+…+2ᵈ=2ᵈ⁺¹−1 узлов, из них 2ᵈ листьев. Глубину нужно определять числом рёбер от корня, иначе возникает сдвиг на один.

    **Пример:** При глубине 3 уровни содержат 1,2,4,8 узлов. Всего 15=2⁴−1 узлов, но только 8 конечных конфигураций. Поэтому стоимость обхода всего дерева и число полных решений отличаются: промежуточные узлы тоже требуют работы.

    **Источник:** [MIT MCS, гл. 13.1–13.5: суммы](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session23/)

19. Как принцип Дирихле доказывает неизбежность коллизий короткого хеша?

    **Ответ:** Для b-битного результата доступно 2ᵇ значений. Если различных входов больше, хотя бы два должны попасть в один выход. Это утверждение о существовании, оно не задаёт вероятность коллизии на случайной выборке.

    **Типичная ошибка:** Путать гарантированную коллизию после 2ᵇ+1 разных входов с вероятностным порогом дня рождения.

    **Источник:** [MIT MCS, гл. 14.8–14.9: Дирихле и включения-исключения](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session27/)

20. Как посчитать объединение двух наборов тестов, если в них 18 и 15 случаев, а 7 общих?

    **Ответ:** Сложение даёт 33 записи, но каждый из 7 общих случаев посчитан дважды. Вычитаем пересечение один раз: 18+15−7=26 различных тестов. Сначала убедитесь, что совпадение тестов определено по содержанию, а не по имени файла.

    **Источник:** [MIT MCS, гл. 14.8–14.9: Дирихле и включения-исключения](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session27/)

21. Как считается объединение трёх множеств?

    **Ответ:** Сложите три размера, вычтите размеры трёх парных пересечений и прибавьте тройное пересечение. Элемент из всех трёх множеств иначе получил бы 3−3=0 вместо 1. Формула требует фактических размеров пересечений, а не предположения независимости.

    **Пример:** Пусть |A|=6,|B|=5,|C|=4, размеры AB,AC,BC равны 2,1,2, а ABC=1. Тогда объединение имеет размер 6+5+4−2−1−2+1=11. Тройной элемент был сначала посчитан трижды, затем вычтен трижды; последнее +1 возвращает его ровно один раз.

    **Источник:** [MIT MCS, гл. 14.8–14.9: Дирихле и включения-исключения](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session27/)

22. Сколько путей из (0,0) в (3,2), если разрешены только шаги вправо и вверх?

    **Ответ:** Каждый путь содержит 3 шага вправо и 2 вверх, всего 5 шагов. Выбираем позиции двух вертикальных шагов: C(5,2)=10. При препятствиях такой подсчёт уже не подходит напрямую, потому что часть последовательностей становится недопустимой.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

23. Как количество двоичных строк без соседних единиц связано с динамическим программированием?

    **Ответ:** Разбейте строки длины n по последнему символу. Окончание 0 допускает любую строку длины n−1; окончание 1 при n≥2 требует предыдущий 0, оставляя длину n−2. Поэтому f(n)=f(n−1)+f(n−2), f(0)=1,f(1)=2.

    **Пример:** Для длины 3 допустимы 000,001,010,100,101 — пять строк. Три из них оканчиваются на 0 и получаются из всех трёх допустимых строк длины 2. Две заканчиваются на 01 и получаются из двух строк длины 1; это разбиение объясняет f(3)=f(2)+f(1)=3+2.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

24. Как посчитать распределение n одинаковых задач по k различимым очередям без ограничений ёмкости?

    **Ответ:** Это неотрицательные целочисленные решения x₁+…+xₖ=n. При k≥1 формула разделителей даёт C(n+k−1,k−1). Если сами задачи различимы, получится другая задача: kⁿ назначений, а не эта формула.

    **Типичная ошибка:** Смешивать одинаковые объекты, различимые задания и порядок заданий внутри очереди.

    **Пример:** Два одинаковых задания и три очереди дают векторы (2,0,0),(0,2,0),(0,0,2),(1,1,0),(1,0,1),(0,1,1): шесть распределений. Если задания назвать A и B, будет 3²=9 назначений: размещения A в первой, B во второй и наоборот теперь различимы. До подсчёта нужно выбрать одну из этих моделей.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

25. Почему число конфигураций тестирования не равно числу обязательных ручных тестов?

    **Ответ:** Произведение мощностей факторов даёт полный набор комбинаций при отсутствии ограничений. Выбор стратегии тестирования дополнительно зависит от взаимодействий факторов и риска ошибок. Попарное покрытие может сократить набор, но не доказывает покрытие ошибок, зависящих от трёх и более факторов.

## Сложный уровень — обоснование и ограничения

26. Почему нельзя всегда делить число линейных записей на число симметрий объекта?

    **Ответ:** Простое деление требует, чтобы каждый объект имел одинаковое число разных представлений. У повторяющихся узоров некоторые повороты ничего не меняют, поэтому размеры классов могут различаться. Нужно явно строить классы эквивалентности либо применять более общий подсчёт орбит.

    **Пример:** Среди четырёхбитных строк с учётом циклических сдвигов класс 0000 содержит одну строку, класс 0101 — две, класс 0001 — четыре. Поэтому деление всех 16 строк на 4 не считает число классов. Необходимо учитывать фактические размеры классов или использовать подсчёт по неподвижным точкам симметрий.

    **Типичная ошибка:** Делить число записей на число поворотов, не проверив одинаковость числа представлений каждого объекта.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

27. Почему вычисление C(n,k) через факториалы может переполниться, даже если ответ помещается?

    **Ответ:** Промежуточные n! и произведение знаменателей часто больше результата на много порядков. Сокращение после переполнения уже не восстанавливает утраченное значение. Для целых используйте точную длинную арифметику, предварительное сокращение либо рекуррентную формулу с контролем промежуточных произведений.

    **Типичная ошибка:** Проверять диапазон только окончательного ответа и игнорировать промежуточное умножение.

    **Пример:** При вычислении C(20,10)=184756 ответ помещается в 32-битный знаковый тип. Но 20!=2432902008176640000 уже не помещается в нём; если сначала вычислить факториал в этом типе, последующее деление не спасёт результат. Используйте способ, для которого доказаны границы каждого промежуточного значения.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

28. Как посчитать C(n,k) без построения всех факториалов?

    **Ответ:** Возьмите k=min(k,n−k) и r=1. На шаге i=1…k обновляйте r=r·(n−k+i)/i; после каждого шага результат целый, поскольку это очередной биномиальный коэффициент. Умножение перед делением может требовать более широкого типа; переставить целочисленное деление без доказательства нельзя.

    **Пример:** Для точной арифметики в Python достаточно следующего варианта; в C++ перед произведением нужна отдельная проверка диапазона.

    ```python
    def choose(n, k):
        if n < 0 or k < 0:
            raise ValueError("n и k должны быть неотрицательными")
        if k > n:
            return 0
        k = min(k, n - k)
        result = 1
        for i in range(1, k + 1):
            result = result * (n - k + i) // i
        return result
    ```

    Для n=5,k=2 промежуточные результаты равны 1→4→10. Здесь 4·5 делится на 2 нацело; выражение `result // i * (...)` в общем случае неэквивалентно.

    **Типичная ошибка:** Выполнять целочисленное деление раньше умножения, когда делимость промежуточного результата не доказана.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

29. Как объяснить сложность перебора всех подмножеств и всех подмасок каждой маски?

    **Ответ:** Для каждой позиции есть три состояния: не в основной маске, в маске без подмаски, в обеих. Поэтому пар (mask,submask) с submask⊆mask ровно 3ⁿ. Это включает пустую подмаску; её исключение уменьшает число до 3ⁿ−2ⁿ.

    **Пример:** Для n=1 допустимы три пары: (0,0),(1,0),(1,1). Для двух позиций каждая независимо выбирает один из этих трёх вариантов, поэтому получаются 3²=9 пар. Если в цикле пропущена нулевая подмаска, для n=2 останется 9−4=5, а не 9.

    **Источник:** [MIT MCS, гл. 14.1–14.2: правила подсчёта](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session25/)

30. Как вывести число строк из n пар правильно вложенных скобок?

    **Ответ:** Это число Каталана C(2n,n)/(n+1). Все последовательности с n открывающими и n закрывающими считаются C(2n,n), а отражение первого плохого префикса позволяет вычесть неправильные. Альтернативно динамика делит строку по паре первой открывающей скобки: c₀=1, cₙ=Σ cᵢcₙ₋₁₋ᵢ.

    **Пример:** Для n=3 возможны ((())), (()()), (())(), ()(()), ()()() — пять последовательностей. Все строки с тремя открывающими и тремя закрывающими дают C(6,3)=20 вариантов, но 15 нарушают неотрицательность баланса некоторого префикса. Формула Каталана даёт 20/(3+1)=5; генерация должна проверять префиксное условие, а не только итоговый баланс.

    **Типичная ошибка:** Считать любые строки с одинаковым числом открывающих и закрывающих скобок правильными: строка )()( имеет нулевой итоговый баланс, но недопустима.

    **Источник:** [MIT 6.006, lecture 23: числа Каталана и скобочные последовательности](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2008/91770ad0733c823eaa5816fed6d7e3fc_lec23.pdf); [Tom Davis: Catalan Numbers, формула и отражение](https://mathcircle.berkeley.edu/sites/default/files/BMC6/pdf0607/catalan.pdf)

31. Что различает число допустимых результатов и стоимость их перечисления?

    **Ответ:** Даже если количество результатов вычисляется быстро по формуле, их запись требует времени хотя бы пропорционально объёму вывода. Для всех n-битных строк это n·2ⁿ бит вывода. Генератор уменьшает пиковую память, но не устраняет необходимость выдать каждый результат.

    **Источник:** [MIT MCS, гл. 14.1–14.2: правила подсчёта](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session25/)

32. Как подсчитывать варианты при нескольких запретах на размеры очередей?

    **Ответ:** Сначала можно снять обязательные минимумы заменой переменных. Верхние ограничения обрабатываются динамикой или включениями-исключениями по нарушениям. Простая формула разделителей без учёта ограничений будет считать запрещённые распределения.

    **Источник:** [MIT MCS, гл. 14.8–14.9: Дирихле и включения-исключения](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session27/)

33. Как комбинаторное доказательство связывает Σ C(r,i)C(s,k−i) с C(r+s,k)?

    **Ответ:** Рассмотрите два непересекающихся набора размеров r и s. k-подмножество общего набора содержит некоторое i элементов из первого и k−i из второго, что даёт произведение. Сумма по всем допустимым i покрывает варианты без повторов; правая часть выбирает сразу из объединения.

    **Пример:** Из r=2 элементов A,B и s=3 элементов C,D,E выбираем k=2. Варианты с 0,1,2 элементами первой группы дают C(2,0)C(3,2)=3, C(2,1)C(3,1)=6 и C(2,2)C(3,0)=1. Сумма 3+6+1=10 совпадает с C(5,2).

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

34. Почему оценка n! существенно меняет решение о полном переборе?

    **Ответ:** Факториал растёт быстрее любой фиксированной степени nᶜ. Добавление одного различимого объекта умножает число перестановок на n+1, а не прибавляет постоянное число вариантов. Для оценки бюджета используйте точные небольшие значения или сумму логарифмов, отдельно учитывая стоимость проверки кандидата.

    **Источник:** [MIT MCS, гл. 13.1–13.5: суммы](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session23/)

35. Как получить число способов оставить ровно k выбранных элементов без соседства среди n позиций?

    **Ответ:** Для выбранных позиций p₁<…<pₖ требуется pᵢ₊₁≥pᵢ+2. Вычитание из pᵢ величины i−1 превращает выбор в обычные k различных позиций среди n−k+1. Поэтому число равно C(n−k+1,k), если n≥2k−1; для k=0 ответ 1.

    **Пример:** Для n=5,k=2 выберем позиции 1 и 4 при нумерации с единицы. После сдвига получаем 1 и 3 среди четырёх позиций; обратное преобразование прибавляет 0 и 1. Так каждая пара без соседства однозначно соответствует обычной паре из 4 позиций, что даёт C(4,2)=6.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

    **Ответ:** Замените xᵢ=yᵢ+1; тогда y₁+y₂+y₃=5, yᵢ≥0. Число решений C(5+3−1,2)=C(7,2)=21. Перебор положительных x₁,x₂ с вычислением x₃=8−x₁−x₂ даёт те же 21 тройку.

    **Проверка:** Каждая сумма равна 8, все компоненты ≥1; при 2 заданиях и 3 непустых очередях решений нет.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

46. Реализуйте число двоичных строк длины n без соседних единиц для n=0…20. Для n≤10 сравните с полным перебором.

    **Ответ:** Используйте f(0)=1,f(1)=2 и f(n)=f(n−1)+f(n−2). Первые значения 1,2,3,5,8,13; f(20)=17711. Для хранения двух предыдущих чисел достаточно постоянного числа переменных, но их разрядность растёт с n.

    **Проверка:** Все случаи n≤10 должны совпасть с фильтрацией двоичных строк; не забудьте единственную пустую строку.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

47. Посчитайте количество пар (mask,submask) для n=0…6, включая submask=0. Проверьте формулу 3ⁿ.

    **Ответ:** Для каждой mask перечисляйте submask по правилу sub=(sub−1)&mask, отдельно завершив после обработки нуля. Получаются 1,3,9,27,81,243,729 пар. Цикл, который после нуля снова вычисляет подмаску, может зациклиться.

    **Проверка:** Сверьте с двойным перебором и условием submask & mask == submask; для n=0 должна быть одна пара (0,0).

    **Источник:** [MIT MCS, гл. 14.1–14.2: правила подсчёта](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session25/)

48. Найдите число перестановок 6 разных задач, в которых задача A идёт раньше B, а C раньше D. Сверьте с перебором.

    **Ответ:** Всего 6!=720 перестановок. Перестановки разбиваются на группы по независимым обменам A↔B и C↔D; в каждой группе из 4 ровно одна удовлетворяет обоим ограничениям. Ответ 720/4=180. Для пересекающихся ограничений такое деление на 4 без доказательства не переносится.

    **Проверка:** Переберите 720 порядков и посчитайте 180 допустимых. После замены условия на A<B<C отдельно пересчитайте, не переиспользуйте знаменатель 4.

    **Источник:** [MIT MCS, гл. 14.4–14.7: перестановки и сочетания](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session26/)

49. Постройте динамику числа правильных скобочных последовательностей из n пар для n=0…8 и генератор для n=3.

    **Ответ:** Для подсчёта используйте c₀=1, cₙ=Σ cᵢcₙ₋₁₋ᵢ. Получатся 1,1,2,5,14,42,132,429,1430. Генератор добавляет открывающую, пока их <n, и закрывающую, пока закрывающих меньше открывающих; для n=3 выдаёт 5 строк.

    **Проверка:** У каждого префикса баланс неотрицателен, общий баланс 0; число уникальных строк должно совпасть с динамикой.

    **Источник:** [MIT 6.006, lecture 23: рекурсия чисел Каталана](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2008/91770ad0733c823eaa5816fed6d7e3fc_lec23.pdf)

50. Распределите 10 одинаковых элементов по 4 различимым буферам ёмкостью не более 3. Найдите количество динамикой и включениями-исключениями.

    **Ответ:** Без ограничений C(13,3)=286. Нарушение xᵢ≥4 после замены xᵢ=yᵢ+4 оставляет 6 элементов: C(9,3)=84 для каждого из 4 буферов. Для пары нарушений остаётся 2 элемента: C(5,3)=10; ответ 286−4·84+6·10=10. Динамика по буферам и текущей сумме должна подтвердить его.

    **Проверка:** Сверьте с перебором 4⁴=256 векторов значений 0…3. При 13 элементах вариантов нет, при 12 — только (3,3,3,3).

    **Источник:** [MIT MCS, гл. 14.8–14.9: Дирихле и включения-исключения](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/resources/mit6_042js15_session27/)
