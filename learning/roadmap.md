Выберите цель, начните с первого незнакомого этапа и двигайтесь дальше после практической проверки. Знать все вопросы библиотеки для этого не требуется. Подготовка к собеседованию — один из способов проверить знания.

## C++ и системная разработка

Подходит для развития из C++ LTE/NR в системное ПО, runtime и инструменты разработки.

| Этап | Что изучить и прочитать | Практика | Когда переходить дальше |
| --- | --- | --- | --- |
| 1. Объекты и владение | C++: память, lifetime, RAII, move semantics; в CS:APP — представление данных | Исправить dangling references, собрать примеры с ASan/UBSan | Объясняете владельца и время жизни каждого объекта |
| 2. Компиляция и исполнение | Toolchain, linking, ABI; CS:APP: машинный код и linking | Собрать статическую и динамическую библиотеку, изучить символы и дизассемблирование | Объясняете путь от исходника до выполнения |
| 3. Linux и память | Процессы, virtual memory, mmap, system calls; CS:APP: virtual memory и system-level I/O | Написать обработчик бинарного файла, проверить через strace | Различаете виртуальную память, физическую память и lifetime C++ |
| 4. Конкурентность | Mutex, condition variable, atomics, happens-before | Сделать ограниченную очередь с остановкой и backpressure; проверить TSan | Обосновываете корректность, завершение и поведение при переполнении |
| 5. Производительность CPU | Cache, TLB, false sharing, NUMA, SIMD; материалы CMU 15-418 | Сравнить layout AoS/SoA и обходы массива; измерить через perf | Объясняете измеренный bottleneck и воспроизводите результат |
| 6. Инженерная практика | Тестирование, sanitizers, fuzzing, benchmark | Собрать pipeline обработки сообщений с тестами и измерением p50/p95/p99 | Документированы корректность, нагрузка и ограничения |

## GPU и параллельные вычисления

Предварительно: уверенный C++, память CPU, базовая многопоточность и линейная алгебра. CUDA используется для практики на совместимом GPU; чтение и CPU-версию можно пройти заранее.

| Этап | Что прочитать | Практика | Критерий освоения |
| --- | --- | --- | --- |
| 1. Архитектура | CMU 15-418: parallel machines; CUDA Guide: programming model | Нарисовать соответствие grid/block/thread и SM/warp | Различаете модель программы и аппаратное выполнение |
| 2. Память GPU | CUDA Guide: memory hierarchy, coalescing, synchronization | Сложение векторов и transpose с проверкой CPU-результата | Объясняете обращения к памяти и границы синхронизации |
| 3. Параллельные алгоритмы | Reduction, scan, histogram | Реализовать reduction, проверить крайние размеры и погрешность | Корректны неполные блоки и численные допуски |
| 4. Измерения | CUDA Best Practices Guide: timing, transfers, performance | Раздельно измерить transfers и kernels, учесть warm-up и синхронизацию | Сравниваете CPU/GPU на одинаковой задаче и данных |
| 5. Оптимизация | Roofline, arithmetic intensity, occupancy, divergence | Оптимизировать transpose или матричное умножение | Показаны профиль до/после и причина ускорения |

## LTE/NR → системы с высокой пропускной способностью

Сохраните телеком-экспертизу как специализацию: timing, scheduling, HARQ, очереди, backpressure, задержки и throughput. Пройдите системный маршрут, затем GPU-маршрут для вычислительных задач. Для сетевого data plane отдельно изучите packet processing, DMA, PCIe, NUMA и RDMA.

Сквозной проект: генератор сообщений → ограниченные очереди → обработка на CPU → измерение latency/throughput → Python-анализ результатов → перенос подходящего вычислительного этапа на GPU. Фиксируйте нагрузку, версии инструментов, ошибки измерения и компромиссы.

## Математика и Python

Математику проходите по зависимости: дискретная математика → линейная алгебра → floating point и численные методы → вероятность и статистика. Анализ и оптимизацию подключайте по задачам; комплексные числа и Фурье — для DSP.

Python изучайте как инструмент автоматизации и вычислительных экспериментов: язык → файлы и процессы → тесты → NumPy → профилирование → интеграция C++.

В Python подготовлено 395 вопросов и задач: 315 по основному маршруту и 80 по дополнительным веткам. Откройте раздел Python → «План обучения и материалы», затем выберите тему. Ответы пока не добавлены; при выборе через библиотеку отключите «Только с ответами».

Математика, архитектура компьютеров и GPU доступны как планы обучения с упражнениями; наличие плана не означает наличие готовых вопросов.

## Другие специализации

Драйверы и firmware: после системной основы — kernel/user space, MMIO, DMA, interrupts, PCIe и платформенная документация. Компиляторы: IR, LLVM, анализ и преобразования программ. Проектирование чипов: цифровая логика, SystemVerilog, RTL и верификация — отдельный маршрут, который здесь пока не разработан.

## Источники и порядок чтения

- [CS:APP, авторский сайт](https://csapp.cs.cmu.edu/3e/): читать тематически по системному маршруту; упражнения обязательны.
- [CMU 15-418: Parallel Computer Architecture and Programming](https://www.cs.cmu.edu/~418/): архитектура параллельных машин, memory consistency, locality и performance; набор материалов зависит от семестра.
- [CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-programming-guide/index.html): programming model → память → синхронизация → углублённые темы.
- [CUDA Best Practices Guide](https://docs.nvidia.com/cuda/cuda-c-best-practices-guide/index.html): измерения и оптимизация после первых корректных kernels.
- [Python Tutorial](https://docs.python.org/3/tutorial/), [NumPy Learn](https://numpy.org/learn/): язык, затем массивы и вычисления.

Ссылка «Источник» в ответе должна подтверждать конкретное утверждение. «Что прочитать» в маршруте объясняет порядок обучения и может охватывать несколько тем.
