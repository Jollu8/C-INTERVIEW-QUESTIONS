# Как добавить материал

1. Создайте Markdown-файл в соответствующем каталоге `content/<section>/` по шаблону `templates/question_file.md`.
2. Используйте нумерованные списки для вопросов и локальные относительные ссылки между соседними темами.
3. Обновите сгенерированные файлы:

	```bash
	python scripts/build_index.py
	python scripts/stats.py
	```

4. Перед отправкой изменений выполните проверки:

	```bash
	python scripts/validate_links.py
	python scripts/validate_meta.py
	pytest
	```

Не добавляйте вручную секреты, временные файлы или артефакты IDE. Если вопрос зависит от версии стандарта или инструмента, укажите это в формулировке или пояснении.
